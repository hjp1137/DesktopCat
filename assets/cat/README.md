# DesktopCat 角色美术资产说明 (Cat Art Assets)

## 一、版权与来源说明
- 本目录下的所有角色 Sprite 序列帧均为 DesktopCat 项目专属**原创制作**（由 `tools/generate_cat_art.py` 程序化矢量超采样生成），严禁任何侵权复制；
- 角色形象设定为萌系暖橙色金斑白腹短毛猫，享有完全独立自主的知识产权。

## 二、规格契约 (Canvas & Anchor Contract)
- **标准画布尺寸**：统一为 `64 x 64` 像素；
- **色彩空间**：RGBA（32位透明通道，无黑边无脏边）；
- **足底基准点 (Foot Lock)**：地面静止与水平移动动画脚底接触点严格锁定在 `(32, 58)` 像素；
- **挂边基准点 (Edge Hang)**：抓挂前爪锚点严格锁定在 `(46, 38)` 像素；
- **贴墙基准点 (Wall Contact)**：抓墙受力爪点严格锁定在 `(48, 38)` 像素。
