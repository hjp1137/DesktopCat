# 20260903 本地外部感知桥接通道方案 (T10)

## 1. 核心目标
建立 DesktopCat (Godot 4.7.2) 与外部感知服务（Python Perception Service）之间的极轻量本地通信协议（Local External Perception Bridge），作为未来屏幕内容感知、几何物理世界映射的数据通信基石。
通信仅限本地 `127.0.0.1`，采用非阻塞 TCP + UTF-8 + NDJSON 协议，不发送屏幕位图，保持对现有小猫行为零干扰与零开销。

## 2. 总体架构设计

### 2.1 拓扑与职责划分
- **Godot 本地 TCP Server**：监听 `127.0.0.1:47831`，仅限本地 IPC，非阻塞 poll 处理客户端连接与数据；
- **ExternalBridge (`scripts/external_bridge.gd`)**：负责 TCP Server 监听、单客户端连接管理、NDJSON 分包解析、Envelope 协议校验、白名单映射与指令分发至 `CommandManager`；
- **CommandManager (`scripts/command_manager.gd`)**：统一接收指令并转发给 Cat，保持与键盘调试、鼠标感知完全相同的优先级与执行路径；
- **Cat (`scripts/cat.gd`)**：接收标准指令与目标坐标执行状态流转与移动；
- **测试工具 (`tools/bridge_test_client.py`)**：仅依赖 Python 标准库的终端交互测试客户端，支持命令注入与 20Hz 压力测试。

### 2.2 协议与消息定义 (Protocol v1)
- **NDJSON 格式**：单行一条完整 JSON，以 `\n` 结尾；
- **Envelope 结构**：`{"v": 1, "type": "...", ...}`；
- **支持消息类型**：
  - `hello`：连接建立后服务端主动下发屏幕与视口信息；
  - `ping` / `pong`：心跳探测与响应；
  - `get_status` / `status`：获取小猫状态、模式与屏幕信息；
  - `command`：分发指令（白名单验证，支持坐标有效性校验）；
  - `error`：统一错误返回（格式错误、未知命令、超出大小等）；
  - `surface_snapshot`：几何数据预留（当前返回 `NOT_IMPLEMENTED`）。

### 2.3 安全与容错边界
- 单条消息大小限制：`MAX_MESSAGE_SIZE = 262144` (256KB)；
- 输入缓冲区大小限制：`MAX_BUFFER_SIZE = 524288` (512KB)；
- 畸形 JSON 与非法指令捕获，确保小猫进程永不崩溃；
- 客户端掉线/重连平滑处理，保持小猫当前状态不被异常更改。
