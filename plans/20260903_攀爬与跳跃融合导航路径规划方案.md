# T22 攀爬与跳跃融合导航路径规划方案 (2026-09-03)

## 一、核心目标
将当前以 Platform 为中心的 NavigationGraph 升级为理解平台与墙面交互的 Surface Traversal Graph：
1. 扩展 Graph Node：新增 `WALL` 节点，由可攀爬且符合 `CatMetrics` 长度要求的垂直墙面生成；
2. 扩展 Navigation Edge：新增 `JUMP_TO_WALL`、`DROP_TO_WALL` 与 `WALL_TO_PLATFORM` 动作边；
3. 严密弹道分析与外侧物理规则：严格复用 T21 墙面吸附与接触几何，计算精确飞入时间与抓墙 Y 范围；
4. 路线搜索与多步骤规划：建立 `TraversalRoute` 与 `TraversalStep`，通过轻量 Dijkstra/A* 搜索短路径；
5. Planner 状态机升级：支持跳跃抓墙、爬墙登顶、抓边翻越全链路受控执行与失败安全兜底。

## 二、数据结构设计
1. **NavigationNodeType 与 NavigationNode 扩展**：
   - 支持 `node_type: NavigationNodeType { PLATFORM, WALL }`；
   - Wall 节点属性：`x`, `y1`, `y2`, `orientation`, `attach_side`, `safe_climb_y1`, `safe_climb_y2`；
   - 过滤长度低于 `capabilities.min_climbable_wall_length` 的短墙与屏幕假墙。
2. **NavigationEdge 扩展**：
   - 新增 ActionType：`JUMP_TO_WALL`、`DROP_TO_WALL`、`WALL_TO_PLATFORM`；
   - 保存字段：`attach_side`、`attach_y_min`、`attach_y_max`、`estimated_climb_time`；
   - `WALL_TO_PLATFORM` 内部包含序列：`WALL_CLIMB -> EDGE_HANG -> CLIMB_UP`。
3. **TraversalRoute 与 TraversalStep**：
   - `TraversalRoute`：`route_id`, `source_surface_id`, `goal_surface_id`, `steps: Array[TraversalStep]`, `current_step_index`, `total_cost`；
   - `TraversalStep`：`step_index`, `action_type`, `from_surface_id`, `to_surface_id`, `parameters: Dictionary`, `timeout`；
   - 原单个 Jump/Drop Plan 统一适配为 1 个 Step 的 Route。

## 三、算法与执行逻辑
1. **JUMP_TO_WALL 弹道验证**：
   - 外侧检测：根据 Wall 左右朝向限制小猫起跳位置必须在外侧；
   - 飞行方程：根据水平间距与速度模式（WALK / RUN）计算飞行时间 $t$，带入下落方程计算飞达时刻的 Y 坐标与垂直速度 $v_y(t)$；
   - 吸附约束：验证到达时刻 $0 \le v_y(t) \le 500\text{px/s}$，且落在 $[safe\_climb\_y1, safe\_climb\_y2]$ 区间内；
   - 轨迹中间遮挡检测：复用 `_is_trajectory_occluded` 确保弹道中途无其他平台阻挡。
2. **WALL_TO_PLATFORM 构建与 T20 翻越复用**：
   - 查询顶部相连 Platform，调用抽取的公共查询 `can_climb_up(surface, edge_side)` 验证顶部尺寸与 clearance；
   - 预估攀爬时长并赋予合理的超时保护上限。
3. **轻量 Dijkstra 路径搜索**：
   - 限制 `MAX_ROUTE_DEPTH = 4`，`MAX_ROUTE_EXPANSIONS = 300`；
   - 环路防护与已访问集合（visited set），杜绝死循环；
   - Direct Jump 成本最低优先，Run Jump 其次，Climb Route 在 Direct 不可达时成为首选。
4. **Planner 多步状态流转**：
   - `APPROACH_TAKEOFF -> READY_TO_JUMP -> AIRBORNE -> ATTACH_WALL -> WALL_CLIMB -> EDGE_HANG -> CLIMB_UP -> LANDED`；
   - 任何异常（miss wall / wrong wall / surface lost / metrics changed）均安全恢复或脱落，严禁强制瞬移。
