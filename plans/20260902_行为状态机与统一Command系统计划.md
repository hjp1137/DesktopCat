# 20260902 行为状态机与统一 Command 系统计划 (T05)

## 1. 任务目标
将 Cat 行为逻辑重构为“自主行为状态机”与“统一外部指令入口”，建立 `CommandManager` 控制中枢，支持 AUTO 自主走走停停与 COMMAND 外部指令控制模式，为未来鼠标、语音、手势及 AI 控制打好基础。

## 2. 详细技术方案

### 2.1 CommandManager 架构 (`scripts/command_manager.gd`)
- 定义基础命令枚举 `CatCommand { STOP, WALK_LEFT, WALK_RIGHT, RESUME_AUTO }`；
- 提供 `send_command(cmd, payload)` 接口，负责将指令分发给 Cat；
- 作为后续所有控制源（鼠标、语音、手势、AI）的统一接入点。

### 2.2 Cat 状态机与控制模式 (`scripts/cat.gd`)
- 定义模式枚举 `ControlMode { AUTO, COMMAND }`；
- 定义状态枚举 `CatState { IDLE, WALK }`；
- 实现标准状态生命周期方法：`enter_state()`、`update_state()`、`exit_state()` 与 `change_state()`；
- 实现统一指令入口 `handle_command(command, payload)`：
  - STOP：进入 COMMAND 模式，切换至 IDLE；
  - WALK_LEFT：进入 COMMAND 模式，朝向左侧，切换至 WALK；
  - WALK_RIGHT：进入 COMMAND 模式，朝向右侧，切换至 WALK；
  - RESUME_AUTO：恢复 AUTO 模式，重置随机走停计时器；
- AUTO 模式保留随机走停（IDLE 1.5~3.5s ↔ WALK 3~7s），COMMAND 模式严格服从指令；
- 保持点击跳跃反馈、左右 `flip_h` 翻转、边界反弹及鼠标穿透。

### 2.3 快捷键测试与主场景接入 (`scripts/main.gd`)
- 初始化并持有 `CommandManager`，绑定小猫实例；
- 键盘数字键 `1`（STOP）、`2`（WALK_LEFT）、`3`（WALK_RIGHT）、`4`（RESUME_AUTO）作为测试入口，统一调用 `CommandManager.send_command()`；
- 保持 TAB 多屏切换与 ESC 安全退出。
