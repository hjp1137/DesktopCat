# 20260902 跳跃、重力与下落物理系统计划 (T06)

## 1. 任务目标
为 DesktopCat 构建完整的垂直物理运动系统（JUMP → FALL → LAND），支持通过统一 `CommandManager` 发送 `JUMP` 指令，并保持水平运动、点击视觉反馈分离、空中鼠标穿透跟随、多显示器适配及安全退出。

## 2. 详细技术方案

### 2.1 状态机扩展与物理参数 (`scripts/cat.gd`)
- 扩展状态机枚举 `CatState { IDLE, WALK, JUMP, FALL }`；
- 配置物理参数：
  - `gravity = 980.0` px/s²
  - `jump_velocity = -420.0` px/s
  - `vertical_velocity = 0.0`
  - `is_grounded = true`
- 动态定义 `ground_y`：基于当前显示器可用区域高度动态计算（`ground_y = vp_size.y - 48.0`），避免硬编码并适配多分辨率；
- 物理更新逻辑（基于 delta）：
  - 起跳：仅在 `is_grounded` 时允许起跳，`vertical_velocity = jump_velocity`，进入 `JUMP` 状态；空中再次收到 JUMP 则忽略并打印提示，禁止二段跳；
  - 上升至最高点：当 `vertical_velocity >= 0` 时自动从 `JUMP` 转为 `FALL`；
  - 下落落地：当 `position.y >= ground_y` 时钳制 `position.y = ground_y`，重置 `vertical_velocity = 0`，`is_grounded = true`，进入 `_on_land()` 恢复地面状态；
- 落地行为恢复：
  - `COMMAND` 模式：根据指令恢复为 `WALK` 或 `IDLE`；
  - `AUTO` 模式：恢复自主走走停停；
- 空中水平运动：起跳时保留水平移动速度，空中碰壁正常反弹；
- 空中接收指令：`STOP`/`WALK_LEFT`/`WALK_RIGHT`/`RESUME_AUTO` 更新水平方向与控制模式，不打断重力下落。

### 2.2 点击反馈与物理彻底分离
- 点击小猫时的 16px 上弹反馈仅作用于 `_animated_sprite.position.y` 视觉子节点（Tween 动画），绝对不修改根节点真实 `position.y` 或垂直物理速度。

### 2.3 鼠标穿透实时跟随空中 Cat (`scripts/main.gd`)
- 空中 Cat 移动时每帧将 `position` 传入 `update_mouse_passthrough`，使点击包围盒实时跟随空中 Cat，地面旧位置恢复穿透。

### 2.4 CommandManager 与快捷键更新 (`scripts/command_manager.gd` & `scripts/main.gd`)
- `CatCommand` 增加 `JUMP`；
- 键盘按键 `5` 触发 `CommandManager.send_command(JUMP)`。
