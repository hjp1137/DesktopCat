# T21 垂直墙面附着与攀爬系统 (Vertical Wall Attachment & Climbing) 方案

## 一、核心原则与目标
1. **统一表面语义 (Surface-Driven)**：小猫只感知 `SurfaceType.WALL` 与 `climbable = true`，绝不硬编码区分图片、按钮、窗口或视觉线条。
2. **物理闭环链条**：
   `FALL / THROW` → `Wall Attach` → `WALL_CLING` → `WALL_CLIMB (UP/DOWN)` → `Wall Top` → `EDGE_HANG` → `T20 CLIMB_UP` → `GROUNDED`。
3. **零作弊与零磁吸**：必须满足横纵速度限制、空间接触判定与外侧接近，严禁隔空瞬间吸附；攀爬过程采用 delta-based 匀速运动，严禁失控 Tween 绕过状态机。
4. **与已有系统解耦与协同**：
   - 严格优先级：`Landing > Edge Grab > Wall Attach > Fall`；
   - 爬到顶端直接转入 T19 `EDGE_HANG` 并复用 T20 `CLIMB_UP`，不重写第二套翻顶逻辑；
   - 鼠标拖拽（`DRAG`）与 `G` 键（`WALL_RELEASE`）拥有最高中断优先级。

## 二、架构设计与核心组件

### 1. `Surface` 与 `SurfaceCandidate` 增加 `climbable` 属性
- 垂直 WALL 满足 `length >= MIN_CLIMBABLE_WALL_LENGTH (48.0px)` 且不是屏幕假墙（`screen:left`, `screen:right`, `screen:top`）时标记为 `climbable = true`。

### 2. `WallAttachment` 数据结构 (`scripts/world/wall_attachment.gd`)
- 弱引用记录当前附着表面信息：`wall_surface_id`, `wall_x`, `wall_y1`, `wall_y2`, `wall_orientation`, `attach_side`, `anchor_y`, `surface_revision_at_attach`。

### 3. 状态机与攀爬运动 (`scripts/cat.gd`)
- `CatState` 新增 `WALL_CLING`, `WALL_CLIMB`；
- 方向枚举 `WallClimbDirection`: `NONE, UP, DOWN`；
- 参数体系：
  - `MIN_CLIMBABLE_WALL_LENGTH = 48.0`
  - `WALL_ATTACH_X_TOLERANCE = 14.0`
  - `MAX_WALL_ATTACH_VERTICAL_SPEED = 500.0`
  - `MAX_WALL_ATTACH_HORIZONTAL_SPEED = 280.0`
  - `WALL_CLING_OFFSET_X = 14.0`
  - `WALL_CLIMB_SPEED = 60.0`
  - `WALL_TOP_EDGE_TOLERANCE = 8.0`
  - `MAX_WALL_ATTACH_DELTA = 150.0`
  - `AUTO_WALL_REACTION_DELAY = 0.5`
  - `AUTO_MAX_WALL_CLIMB_DURATION = 4.0`
- 挂墙时 `vertical_velocity = 0`, `horizontal_velocity = 0`, `is_grounded = false`, 暂停重力模拟；
- 沿墙运动为纯 delta-based 线性推进，支持随时反向、STOP 与脱手。

### 4. 交互与指令分发
- `CommandManager`: 新增 `WALL_CLIMB_UP`, `WALL_CLIMB_DOWN`, `WALL_RELEASE`；
- 快捷键：爬墙状态下 `U` 爬上、`J` 爬下、`G` 释放，非爬墙状态保留原有调试功能；
- 调试视图 `F18`：可视化绘制可爬墙面、附着点、抓墙范围与到顶转换点。

## 三、自验证规划
1. **单元测试用例 71～80 (`scripts/test_runner.gd`)**：
   - 测试 71: `climbable` 属性标记与屏幕假墙过滤；
   - 测试 72: `WallAttachment` 数据结构与字段属性序列化；
   - 测试 73: 下落 Swept 抓墙（左侧外侧接近、朝向向右、附着坐标计算正确）；
   - 测试 74: 右侧外侧抓墙与朝向对称自适应；
   - 测试 75: 超速下落（$v_y = 800$）或过远（距离 40px）拒绝抓墙（零磁吸）；
   - 测试 76: `WALL_CLIMB` 连续向上/向下爬行、STOP 转 Cling 与中途反向；
   - 测试 77: 爬到 Wall Top 自动平滑过渡为 `EDGE_HANG` 并顺利触发 T20 `CLIMB_UP` 登顶；
   - 测试 78: 爬墙中表面平移跟随、超大位移（$>150\text{px}$）脱落与等价 Rebind；
   - 测试 79: 用户 DRAG 拖拽与 G（`WALL_RELEASE`）瞬间脱落进入 FALL；
   - 测试 80: AUTO 模式停顿 0.5s 自动往上爬、翻越登顶闭环与长墙超时脱落。
2. **多表面着陆回归验证 (`scripts/test_fusion_landing.gd`)**；
3. **PCK 打包与模式验证 (`scripts/build_standalone.gd`)**。
