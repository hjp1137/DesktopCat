# 任务T25：屏幕视觉占据与“猫眼物理世界”感知原型实施计划

## 一、任务背景与痛点根因

当前 DesktopCat 已完成 T21～T24 能力（垂直攀爬、攀爬导航、自主探索及动作美术）。
然而在**屏幕物理环境感知层**存在根本性缺陷：
- 现有实现过度依赖 OCR、UIA、文字、图标、细碎 Bounding Box，直接转化为台阶；
- 导致一行文字被切碎为几十个字符物理块，碎片表面（Fragmentation）严重，小猫行走和跳跃频繁被打断；
- 误把 UI 元素和视觉细节直接当作物理实体，缺乏物理抽象与世界简化。

**核心设计哲学**：
> **DesktopCat 不是在识别 UI，它是在感知自己生活的二维世界。**
> **中间感知可以复杂，但最终提供给猫的世界必须简单。**
> **不要追求还原屏幕，而要故意丢掉绝大多数对猫没有物理意义的信息。**

---

## 二、架构设计与总体方案

### 1. 三路并行感知架构（A/B/C Prototype）
- **Mode A (Legacy Perception)**：基线对照组，保持现有 Window + UIA + 简单差分线段机制不变，不删除旧实现（Gate 1）；
- **Mode B (OpenCV Visual Perception)**：纯视觉路线，截屏 -> 灰度/HSV -> 自适应阈值 -> Canny 边缘 -> 形态学闭运算填补笔画空隙 -> 连通域与轮廓分析 -> 提取水平/垂直外轮廓物理表面，完全独立于 UI 语义；
- **Mode C (Hybrid Physical Perception)**：混合感知路线（重点路线），以视觉证据为基础，融合 UI 结构语义 Hint（辅助调节置信度、合并段落、抑制内部细节），结合 Cat-scale 与时间滤波，输出极简稳定的物理表面。

### 2. 屏幕物理编译器（Screen Physics Compiler）
流水线设计：
```text
Screen Screenshot (Win32 GDI / DirectX capture)
      ↓
Visual Evidence (OpenCV Adaptive Thresh + Canny + Gradient)
      ↓
Candidate Regions (Connected Components & Contours)
      ↓
Texture Suppression (高纹理图片/视频区域内部抑制，仅留外边界与顶边)
      ↓
Cat-scale Processing (基于猫宽、脚宽自适应合并与滤波，消除硬编码魔法数字)
      ↓
Temporal Filter (时间置信度积分，剔除光标/闪烁/动态噪点，提供稳定表面)
      ↓
Physical Simplification & Surface Extraction
      ↓
Surface World (Platform / Wall / Ledge / Void)
```

### 3. 调试可视化系统（Debug Visualization Overlay）
支持 7 种 Debug 视图模式：
- **Mode 1**: Raw Screen
- **Mode 2**: Raw Visual Evidence (Edge / Contrast / Binary)
- **Mode 3**: Occupancy / Candidate Region (视觉占据候选块)
- **Mode 4**: Merged Region (Cat-scale 尺度聚合块)
- **Mode 5**: Stable Region (经时间滤波后的稳定区域)
- **Mode 6**: Final Surface (最终 Platform / Wall / Ledge)
- **Mode 7**: Side-by-side / Comparison (A: Legacy vs B: OpenCV vs C: Hybrid)

### 4. 量化指标体系（Metrics）
- `candidate_region_count`
- `final_surface_count`
- `stable_surface_count`
- `average_surface_length`
- `fragmentation_count`（同一段落/文本行的表面碎片数）
- `frame_to_frame_surface_change`（Temporal Jitter，静态页面的表面变动次数）
- `reduction_ratio`（原始候选数到最终表面数的压缩比）
- `processing_time_ms`（`capture_ms`, `cv_ms`, `merge_ms`, `surface_ms`, `total_ms`）

## 三、实施步骤

1. **新建 `tools/perception/cat_physics_compiler.py`**：
   - 封装 `ScreenPhysicsCompiler` 核心流水线；
   - 实现 Mode A (Legacy)、Mode B (OpenCV)、Mode C (Hybrid) 三路提取器；
   - 实现 `TextureSuppressor` 高纹理抑制器；
   - 实现 `TemporalFilter` 时间稳定追踪器；
   - 实现 `CatScaleAdapter` 猫尺度参数推导器；
   - 实现 `MetricsCollector` 量化指标收集器。
2. **升级 `tools/perception/perception_service.py` 与配置**：
   - 将编译器接入感知服务，定期将三路数据与量化指标通过 `t25_perception_snapshot` 广播给 Godot。
3. **编写 Python 自动化测试 `tools/perception/test_t25_physics_compiler.py`**：
   - 覆盖合成文本行碎片抑制、图片纹理抑制、动态光标时间滤波、猫尺度自适应与量化指标测试。
4. **新建 Godot `scripts/world/cat_physics_world_model.gd`**：
   - 存储 T25 三路表面与 6 阶段调试层数据；
   - 实现全套 Debug Overlay 绘制与 Mode 1~7 切换；
   - 实现屏幕 HUD 量化仪表盘展示。
5. **升级 `scripts/external_bridge.gd` 与 `scripts/main.gd`**：
   - 解析 `t25_perception_snapshot`，双向同步 CatMetrics；
   - 注册 `F7` 开启 T25 猫眼物理调试、数字键 `1~7` 切换调试层、`F6`/`8` 切换 A/B/C 感知模式；
   - 遵循 Gate 10，小猫活动与现有系统保持隔离运行。
6. **编写 Godot 单元测试并在 `scripts/test_runner.gd` 扩增测试 136~150**。
7. **运行全量自动化测试自验证闭环，并进行真实桌面多场景验证与量化指标记录**。
8. **编写 Walkthrough 成果说明并追加开发日记**。
