# 20260902 基础工程与移动验证计划 (T01)

## 1. 目标与背景
建立最小可运行的 Godot 4.7.2 GDScript 项目，验证引擎环境、项目工程配置、场景树、GDScript 语法解析及小猫基础移动边界转向逻辑。

## 2. 详细技术方案

### 2.1 目录结构与版本控制
- 创建 Git 仓库与标准 Godot `.gitignore`
- 规划工程结构：
  - `project.godot`：Godot 项目配置，配置项目名 `DesktopCat` 与主场景 `scenes/main.tscn`
  - `scenes/main.tscn`：主场景
  - `scripts/main.gd`：主场景控制脚本
  - `scripts/cat.gd`：小猫实体脚本（包含临时图形绘制与移动/转向逻辑）
  - `assets/`：资源目录（预留）
  - `README.md`：项目说明文档

### 2.2 临时猫形占位对象设计
- 在 `scripts/cat.gd` 中利用 Godot 2D 自定义绘制 `_draw()` 绘制清晰醒目的小猫图形：
  - 身体（椭圆/圆形或圆角矩形）
  - 猫耳（三角形）
  - 眼睛与胡须
- 不依赖外部图片素材，轻量自闭环。

### 2.3 移动与边界转向逻辑
- 小猫初始位置设置在窗口中心。
- 设定移动速度 `speed`（可配置，如 200.0 像素/秒）与移动方向 `direction`（1 为向右，-1 为向左）。
- 在 `_process(delta)` 中使用 `delta` 驱动位移。
- 动态获取当前视口边界，当小猫边缘接触到窗口右/左边界时反转移动方向并翻转绘制水平朝向，严格钳制在窗口内。

### 2.4 验证与交付标准
- 使用 Godot Console 执行语法检查与加载运行。
- 确认无 GDScript 解析报错，无运行时异常。
- 提交 Git commit: `feat(T01): initialize DesktopCat and basic cat movement`。
