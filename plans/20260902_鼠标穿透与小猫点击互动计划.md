# 20260902 鼠标穿透与小猫点击互动计划 (T03)

## 1. 任务目标
实现 Windows 桌面宠物鼠标穿透与小猫点击互动：
- 全屏透明区域：鼠标完全穿透到 Windows 桌面及下方所有应用（Chrome、文件夹、桌面图标等）；
- 小猫所在区域：接收鼠标交互；
- 点击区域实时跟随小猫移动；
- 点击小猫时输出控制台日志 `Cat clicked!` 并伴随轻量视觉弹跳反馈，且不破坏自主左右移动与碰边转身；
- 保持多显示器 TAB 切换与 ESC/Alt+F4 安全退出；
- 构建单文件独立 EXE 并进行自验证。

## 2. 详细技术方案

### 2.1 鼠标穿透区域动态更新 (`scripts/main.gd`)
- 提供 `update_mouse_passthrough(cat_pos: Vector2)`：
  - 基于小猫当前坐标计算包围矩形多边形（例如 64x64 像素范围）；
  - 调用 `DisplayServer.window_set_mouse_passthrough(polygon)`；
  - 多边形内接收事件，其余全屏透明区域完全穿透到 Windows 桌面。

### 2.2 小猫点击检测与轻量反馈 (`scripts/cat.gd`)
- 在 `_process(delta)` 中持续更新位置并调用 `main.update_mouse_passthrough(position)`；
- 在 `_unhandled_input(event)` 中检测鼠标左键点击；
- 判定点击落在小猫包围盒内时触发 `_on_clicked()`：
  - 控制台打印 `Cat clicked!`；
  - 启动轻量 `bounce_offset_y` 动画（向上弹起 16 像素并平滑回落）；
  - 绘制时叠加 `bounce_offset_y`，不影响 `position.x` 移动。

### 2.3 验证与交付标准
- 单元与集成测试验证穿透多边形生成与点击事件响应；
- 本机运行验证透明、穿透、点击与安全退出；
- 重新构建 `build/DesktopCat_Standalone.exe`；
- 提交 Git commit: `feat(T03): add mouse passthrough and cat click interaction`。
