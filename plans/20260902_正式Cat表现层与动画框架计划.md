# 20260902 正式 Cat 表现层与动画框架计划 (T04)

## 1. 任务目标
将开发占位小猫升级为 `AnimatedSprite2D` 驱动的角色表现层，建立 `idle` 与 `walk` 动画框架及基础走走停停行为，同时保持桌面 Overlay、鼠标穿透、点击反馈、多屏切换与安全退出等已有功能。

## 2. 详细技术方案

### 2.1 临时原创动画素材 (`assets/cat/placeholder/`)
- 编写素材生成工具 `scripts/generate_placeholder_frames.gd`，生成 64x64 原创 PNG 帧：
  - `idle_01.png` ~ `idle_04.png`：4 帧，4 FPS，轻微呼吸起伏与尾巴轻摆；
  - `walk_01.png` ~ `walk_06.png`：6 帧，10 FPS，四足交替迈步与身体起伏；
- 素材底部居中对齐，避免切换动画时脚底抖动或身体错位。

### 2.2 场景独立化与节点组织 (`scenes/cat.tscn`)
- 建立独立 Cat 场景：
  - `Cat` (Node2D, 挂载 `scripts/cat.gd`)
    - `AnimatedSprite2D` (加载 `SpriteFrames`，支持 idle/walk 动画及 `flip_h` 水平翻转)
    - `Area2D` + `CollisionShape2D` (定义 60x60 矩形 Hitbox)
- 在 `scenes/main.tscn` 中实例化 `cat.tscn`。

### 2.3 状态与行为控制逻辑 (`scripts/cat.gd`)
- 定义基础状态 `enum State { IDLE, WALK }`：
  - WALK：持续 3.0 ~ 8.0 秒，以 `speed` 左右巡逻，碰边转向，播放 `walk` 动画；
  - IDLE：持续 1.5 ~ 4.0 秒，停在原地，播放 `idle` 动画；
- 左右朝向：通过 `animated_sprite.flip_h` 翻转，不修改 `scale.x`；
- 点击反馈：保留点击检测与控制台日志 `Cat clicked!`，通过 Tween 控制 Sprite 的 `position.y` 产生 16 像素弹性跳动，不中断左右移动和当前状态。

### 2.4 测试与交付

- 更新打包脚本，重新构建 `DesktopCat_Standalone.exe`；
