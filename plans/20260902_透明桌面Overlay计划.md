# 20260902 透明桌面 Overlay 计划 (T02)

## 1. 任务背景与目标
将 DesktopCat 改造为真正的 Windows 桌面宠物透明 Overlay：
- 无标题栏与无边框（Borderless）；
- 背景逐像素完全透明（Transparent Background & Per-pixel transparency）；
- 置顶显示（Always On Top）；
- 自动适配当前屏幕尺寸与位置，覆盖整个屏幕显示区域；
- 小猫保持 T01 的左右巡逻、碰边转身逻辑，并自动适配全屏新视口宽度；
- 提供 ESC 键与 Alt+F4 安全退出机制；
- 保持不引入第三方插件、不实现鼠标穿透（属于后续任务）。

## 2. 详细技术方案

### 2.1 ProjectSettings 配置 (`project.godot`)
- 启用透明与无边框：
  - `display/window/size/transparent=true`
  - `display/window/size/borderless=true`
  - `display/window/size/always_on_top=true`
  - `display/window/per_pixel_transparency/allowed=true`
  - `rendering/viewport/transparent_background=true`

### 2.2 动态屏幕适配与退出控制 (`scripts/main.gd`)
- 在 `_ready()` 中：
  - 设置根视口 `get_tree().root.transparent_bg = true`；
  - 获取当前窗口 `get_window()`，如果处于 Windows/GUI 模式：
    - 读取 `DisplayServer.window_get_current_screen()`；
    - 读取屏幕位置 `DisplayServer.screen_get_position(screen)` 与屏幕尺寸 `DisplayServer.screen_get_size(screen)`；
    - 设置 `window.position` 与 `window.size`，使窗口精准覆盖当前屏幕；
    - 确保 `window.borderless = true`、`window.transparent = true` 与 `window.always_on_top = true`；
- 在 `_unhandled_input(event)` 中：
  - 检测 ESC 按键（`KEY_ESCAPE` 或 `ui_cancel`），触发 `get_tree().quit()` 安全退出。

### 2.3 小猫移动适配 (`scripts/cat.gd`)
- 验证小猫的 `_get_viewport_size()` 逻辑，在窗口覆盖整个屏幕后能够自动响应全屏视口尺寸（如 2880 宽），在 `[body_radius, screen_width - body_radius]` 范围内左右往返巡逻并在边缘反弹。

### 2.4 测试与验证方案
- 单元测试与集成测试验证窗口属性设置、退出响应与全屏位移反弹；
- 真实 Godot Console 启动验证：检查透明渲染、无边框、Always On Top、屏幕尺寸适配及 ESC 退出。
- 更新成果说明与开发日记，提交 Git commit: `feat(T02): add transparent desktop overlay`。
