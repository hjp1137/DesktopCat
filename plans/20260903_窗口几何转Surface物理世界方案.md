# 20260903 窗口几何转 Surface 物理世界方案 (T12)

## 1. 背景与核心目标
在 T11 中已实现轻量获取可见顶层窗口几何矩形（Window Rect）并通过 TCP 传入 Godot 存储于 `WindowWorldModel`。
T12 的核心任务是在 Godot 侧将 Window Rect 转换为桌面猫咪物理世界可以理解的几何表面（Surface），包括：
- `PLATFORM`（可站立顶边与不可站立底边、屏幕地面与屏幕顶部）；
- `WALL`（窗口左右边缘、屏幕左右边界墙）。
建立正式的 `SurfaceWorldModel`，提供轻量第一版矩形遮挡计算（Top Platform Occlusion Simplification）与基础空间查询 API。
**严格边界**：T12 不创建 Godot 物理碰撞体（StaticBody2D/CollisionShape2D），不修改猫咪现有物理与 ground_y 逻辑。

## 2. 核心架构与数据结构
1. **`Surface` 结构 (`scripts/world/surface.gd`)**：
   - 继承 `RefCounted`，表达二维世界线段表面。
   - 字段：`id`, `source_id`, `source_type` ("WINDOW", "SCREEN"), `surface_type` (PLATFORM / WALL), `orientation` (TOP / BOTTOM / LEFT / RIGHT), `x1`, `y1`, `x2`, `y2`, `walkable` (bool), `dynamic` (bool), `length` (float)。
   - 稳定 ID 规范：`<wid>:top`, `<wid>:bottom`, `<wid>:left`, `<wid>:right`；遮挡切分产生 `<wid>:top:0`, `<wid>:top:1`；屏幕边界为 `screen:ground`, `screen:left`, `screen:right`, `screen:top`。
2. **`SurfaceWorldModel` (`scripts/world/surface_world_model.gd`)**：
   - 继承 `Node2D`，挂载于主场景；
   - 数量控制：`MAX_SURFACES = 2048`；
   - 长度过滤：`MIN_PLATFORM_LENGTH = 48.0` px，`MIN_WALL_LENGTH = 48.0` px；
   - 遮挡剔除（Occlusion）：对每个 Window A 的 TOP 边缘，遍历 Z-Order 更高的窗口 B，求交并扣除被遮挡的水平线段区间，剩余片段二次过滤；
   - 变动检测：几何未发生实质变化时不递增 `surface_revision`，变化时递增并发出 `surface_world_updated` 信号；
   - 查询 API：`get_all_surfaces()`, `get_walkable_surfaces()`, `get_walls()`, `get_surface_by_id(id)`, `get_walkable_surfaces_near_y(y, tol)`, `find_surfaces_in_rect(rect)`；
   - 独立调试渲染：按 `F9` 切换绘制绿色平台线与黄色墙体线，与 F8 窗口线框独立，不破坏鼠标穿透。

## 3. 验证与回归计划
- 单元测试：验证 Rect 转换、4 条边提取、遮挡切分、全遮挡剔除、尺寸过滤与稳定 ID；
- 集成测试：模拟快照更新、F9 绘制切换、屏幕切换清空；
- 端到端测试：联动 `window_perception.py`，测试独立 EXE，验证拖动 Chrome 实时切割更新与 5Hz 低开销。
