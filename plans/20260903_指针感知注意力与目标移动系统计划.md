# 20260903 指针感知、注意力与目标移动系统计划 (T09)

## 1. 任务目标
构建通用指针感知与目标移动系统，让 Cat 感知 Windows 鼠标位置并表现出注视（Attention）与好奇跟随（Curiosity Chase），提供输入源无关的通用目标移动接口，保持桌面鼠标穿透与已有状态机体系。

## 2. 详细技术方案

### 2.1 独立 MousePerceptionController (`scripts/mouse_perception_controller.gd`)
- 使用 `DisplayServer.mouse_get_position()` 读取全局鼠标坐标；
- 根据当前屏幕可用区域矩形（`screen_get_usable_rect`）转换为当前 Overlay 局部像素坐标；
- 当鼠标离开当前屏幕时取消 Attention 与 Chase；
- 采样频率：20Hz（0.05s 间隔），计算鼠标移动速度与小猫距离；
- 被动注意力：`attention_radius = 400.0` px，`attention_exit_radius = 460.0` px（滞后区间），IDLE/SIT 时发送 `LOOK_AT_POSITION`；
- 好奇跟随 (Curiosity Chase)：AUTO 模式下鼠标快速移动时触发 2.5~4.5 秒追逐，结束后进入 15 秒冷却；
- 显式调试模式（快捷键 C）：Toggle 持续跟踪鼠标目标。

### 2.2 通用目标指令扩展 (`scripts/command_manager.gd`)
- 扩展指令：`LOOK_AT_POSITION`、`MOVE_TO_POSITION`、`CLEAR_TARGET`；
- 指令输入源无关，为未来手势与 AI 预留通用接口。

### 2.3 Cat 状态机与目标移动 (`scripts/cat.gd`)
- 维护通用 `attention_target_pos` 与 `move_target_pos`；
- `LOOK_AT_POSITION`：IDLE/SIT 状态下带 20px 死区转头，WALK/RUN 状态保持移动朝向优先，SLEEP/DRAG 忽略；
- `MOVE_TO_POSITION`：带 `pointer_follow_distance = 64.0` px 偏置与 `target_reached_radius = 50.0` px 达到死区，不压住鼠标；
- 显式用户指令与 DRAG 拥有最高优先级，立即打断自动追逐。
