# 20260903 统一表面融合与几何简化方案 (T16)

## 1. 目标与定位
- **多源归一 (Perception to Surface)**：将 Window Geometry (T11)、UI Automation (T14) 与 Visual Geometry (T15) 三大感知源统一转换为规范化的 `SurfaceCandidate`；
- **几何简化与融合 (Fusion & Simplification)**：经过尺寸过滤、UI容器剔除、同源/跨源去重、近共线合并、窗口遮挡裁剪、4px量化与时序平滑，生成精简、稳定的统一物理世界；
- **单一真理入口 (Single Source of Truth)**：`SurfaceWorldModel` 成为 Cat Physics 的唯一物理世界查询入口。小猫物理（T13 Swept Landing、平台行走、动态跟随）完全对感知来源透明，不为 Text/Button/Visual 增加特例代码；
- **零破坏原则**：绝对不破坏 T13 物理、不影响全屏鼠标穿透、保证窗口与屏幕地面基础立足绝对可靠。

## 2. 总体数据链路
```
[WindowWorldModel] ────┐
                       │
[UIElementWorldModel] ─┼→ [SurfaceFusionBuilder]
                       │        ↓ (Candidates 生成 & 优先级排序)
[VisualWorldModel] ────┘        ↓ (容器过滤、短线过滤、父子/重合去重、共线合并)
                                ↓ (窗口遮挡切分、4px量化、丢失Grace与陈旧剔除)
                       [SurfaceWorldModel] (原子提交更新 commit)
                                ↓
                        [T13 Cat Physics]
                                ↓
                               🐱
```

## 3. 关键规则与超参集中配置
- **来源优先级 (Source Priority)**：SCREEN (100) > WINDOW (90) > UIA (80) > VISUAL (60)；
- **UI 容器类型过滤**：默认过滤 Pane, Group, Document, List, Tree, Toolbar, Menu 等容器，不生成 Platform；
- **允许 UI 控件**：Text, Hyperlink, Button, Edit, Image, ListItem, TreeItem, TabItem, MenuItem, Custom；
- **最小平台长度**：
  - `MIN_PLATFORM_LENGTH = 48.0` px（通用平台与窗口顶边）；
  - `MIN_TEXT_PLATFORM_LENGTH = 48.0` px（文字行最小长度，过滤标点与单字符）；
  - `MIN_WALL_LENGTH = 48.0` px；
- **去重与合并容差**：
  - `MERGE_Y_TOLERANCE = 4.0` px；
  - `MERGE_GAP = 16.0` px；
  - `OVERLAP_DEDUP_THRESHOLD = 0.80`（重叠率超过 80% 视为重复，保留高优先级来源并按需并集拉长）；
- **网格量化与平滑**：
  - `FUSION_QUANTIZATION = 4.0` px；
  - `FINAL_SURFACE_MISSING_GRACE_MS = 600` ms（UIA/Visual 临时漏检保护）；
  - `WINDOW_MISSING_GRACE_MS = 100` ms（窗口关闭即时掉落）；
  - `STALE_PROVIDER_TIMEOUT_MS = 4000` ms；
  - `FUSION_DEBOUNCE_MS = 50` ms（合并三路感知密集更新）；
  - `MAX_SURFACES = 1024`。

## 4. 融合核心算法流程
1. **生成候选集合 (Candidate Generation)**：
   - SCREEN：生成 `screen:ground`, `screen:left`, `screen:right`, `screen:top`；
   - WINDOW：复用 T12，提取 TOP (walkable), LEFT/RIGHT (wall), BOTTOM (non-walkable)；
   - UIA：过滤容器，Text 提取顶边，Button/Edit 提取顶边 (walkable)，Image 提取顶边 (walkable) 与侧边 (wall)；同 Window 内同行相邻 Text 片段执行行内合并；
   - VISUAL：Horizontal Line 转 Platform，Vertical Line 转 Wall，Rect 转 Platform + Wall；
2. **多层过滤与简化 (Multi-Stage Simplification)**：
   - 过滤长度不足及非合法边界；
   - 同源/跨源去重：按 Y 排序与 X 重叠比较，保留高优先级；
   - 近共线合并：将同类断裂横线合并为完整平台；
   - 窗口遮挡处理：针对 UIA/Visual 执行顶层窗口矩形遮挡剔除与裁剪；
3. **时序平滑与原子提交 (Temporal Grace & Atomic Commit)**：
   - 维护 Grace 缓存，新集合计算后原子赋值 `surfaces_by_id = new_surfaces`；
   - 仅在几何签名改变时递增 `surface_revision`。
