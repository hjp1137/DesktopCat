# 平台边缘攀爬翻越系统 (Platform Edge Climb-Up) 方案 (T20)

## 一、方案目标与核心理念
在 T19 平台抓边与悬挂系统 (Platform Edge Grab & Hang) 的基础上，实现小猫从悬挂状态 (`EDGE_HANG`) 翻跃登上平台顶部的完整物理与运动状态链：
1. **完整闭环**：`FALL` → `EDGE_HANG` → `CLIMB_UP` → `LAND / GROUNDED` → `IDLE / AUTO`；
2. **纯正状态机设计**：`CLIMB_UP` 为正式 `CatState`，严禁通过失控 Tween + IDLE 绕过状态机与时序清理；
3. **两段式可见受控运动 (Procedural Motion)**：先垂直上拉 (`PULL_UP`)、后向内平移 (`SHIFT_IN`)，严禁瞬间 Teleport，严禁斜穿平台几何；
4. **动态自愈与零作弊**：全程追踪动态 Surface 位移（滚动/移动），位移超限（$>150\text{ px}$）或表面消失且重绑失败时立即取消并自然转入 `FALL`，绝不爬空气；
5. **范围限定**：本任务仅实现平台边缘翻越登顶（Edge → Platform Top），不实现竖直墙面连续攀爬（Wall Climb）。

## 二、核心架构与数据结构
1. **CatState 扩展**：
   - 枚举新增 `CLIMB_UP`；
   - 攀爬期间 `is_grounded = false`，`current_surface_id = ""`，停用重力模拟与常规 Swept Landing；
   - 内部状态相位：`NONE`, `PULL_UP`, `SHIFT_IN`, `SETTLE`。
2. **ClimbTarget 数据结构 (`scripts/world/climb_target.gd`)**：
   - 记录 `surface_id`, `edge_side` (LEFT/RIGHT), `edge_position`；
   - 记录 `target_foot_x`, `target_foot_y`, `start_position`, `pull_up_position`, `target_position` 与 `surface_revision_at_start`；
   - 确保只能翻上被抓取的同一个表面。
3. **平台落脚点与可行性 (Climb Feasibility)**：
   - 落脚点偏移：`LEFT` 侧 $x_1 + \text{inward\_margin}$，`RIGHT` 侧 $x_2 - \text{inward\_margin}$；
   - 平台长度门槛：`MIN_CLIMB_UP_PLATFORM_LENGTH`（$\ge 48\text{ px}$），长度不足时安全拒绝翻越；
   - 空间净空校验 (Landing Clearance)：基于 Cat 包围盒检查落脚区域上方是否存在遮挡表面。

## 三、受控运动控制与参数
1. **两段式轨迹**：
   - `PULL_UP`：身体由悬挂位置垂直拉升至落脚高度（持续 `CLIMB_PULL_UP_DURATION = 0.3`s）；
   - `SHIFT_IN`：身体从外侧向平台内部平移到位（持续 `CLIMB_SHIFT_IN_DURATION = 0.25`s）；
   - 整体攀爬耗时约 0.55s，基于 delta 累加时间平滑插值（smoothstep）；
   - 超时强行保护：`CLIMB_UP_TIMEOUT = 2.0`s。
2. **核心物理与几何参数**：
   - `CLIMB_INWARD_MARGIN = 20.0`px（落脚点距边缘安全内缩裕量）；
   - `MIN_CLIMB_UP_PLATFORM_LENGTH = 48.0`px（翻越所需最小平台跨度）；
   - `CLIMB_CLEARANCE_MARGIN = 4.0`px（净空检查包围盒膨胀裕量）；
   - `MAX_CLIMB_TARGET_DELTA = 150.0`px（表面移动最大容忍位移）；
   - `AUTO_CLIMB_REACTION_DELAY = 0.4~0.8`s（AUTO 模式悬挂至翻越前的视觉停顿）；
   - `CLIMB_COOLDOWN = 1.5`s（翻越成功后的防频繁重攀冷却）。

## 四、模式、指令与交互响应
1. **AUTO 模式**：
   - 悬挂后经过停顿（0.4~0.8s），优先调用 `check_climb_feasibility()`；
   - 可行则自动触发 `CLIMB_UP`，成功登顶后转入短期 IDLE（0.5s）再交回生活调度；不可行则超时释放脱手 (`FALL`)。
2. **COMMAND 模式与快捷键**：
   - 悬挂时按 `H` 触发 `CLIMB_UP`，按 `G` 触发 `RELEASE_EDGE`；
   - 鼠标拖拽（`DRAG`）最高优先级瞬间中断攀爬并清理抓取；
   - 普通指令（WALK/RUN/JUMP）在攀爬过程中安全忽略。
3. **T18 自主规划器协同**：
   - 若抓取的表面为当前穿越目标（`target_surface_id`），规划器挂起等待；
   - 监听 `climb_completed(surface_id)` 信号，若成功登顶则结算为 SUCCESS，并递增 `edge_grab_recovery_success` 统计；
   - 若抓错平台，平稳结算原计划并允许小猫安全登顶恢复自主生活。
4. **F17 调试可视化**：
   - 快捷键 `F17` 切换，绘制悬挂起点、Pull-Up 拐点、Landing 终点、Clearance 框与当前相位。
