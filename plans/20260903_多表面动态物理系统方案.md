# 20260903 多表面动态物理系统方案 (T13)

## 1. 目标与定位
正式移除“桌面宠物世界仅有一个单一 ground_y”的硬编码假设，将小猫站立点升级为 `current_surface_id` / `current_surface`，使小猫能够真正将真实屏幕上的各个 Window Top 与 screen:ground 当作同等的可站立物理表面（walkable PLATFORM）。

## 2. 核心设计原则
1. **统一接触点**：Cat Root 作为脚底中心，提供 `get_foot_position() -> Vector2`，所有 Landing、Sweep 与 Support 判定基于统一接触点。
2. **轻量 Swept Landing**：下落（FALL）时使用 `previous_foot_y` 到 `next_foot_y` 的线段扫描，杜绝高速下落穿透平台；多候选平台选择首个交叉的最小 Y 平台；向上跳跃可穿过平台（One-Way Platform）。
3. **连续支撑与走出边缘**：已着陆状态每帧验证当前表面支撑范围（带 `support_margin`），走出边缘或表面消失即进入抛物线下落（FALL）。
4. **表面重新绑定 (Rebind)**：处理窗口遮挡分割导致的 ID 变化，先在脚底附近容差范围内查找同高度表面，找不到再下落。
5. **动态窗口跟随**：当小猫站立于动态窗口平台时，窗口拖动位移在合理阈值（`MAX_SURFACE_ATTACH_DELTA = 150px`）内时小猫同步跟随；超限安全解绑下落。
6. **兼容性与调试**：保留 `ground_y` 作为兼容属性；新增 `F10` 物理调试线框，高亮当前站立表面与脚底接触点，不阻挡鼠标穿透。

## 3. 详细模块设计与实现规划
- **Phase 1: Cat 物理模型升级 (`scripts/cat.gd`)**
  - 引入 `current_surface_id`、`current_surface`、`surface_world_model` 引用；
  - 实现 `get_foot_position() -> Vector2` 与 `foot_offset`；
  - 编写 `_check_swept_landing(prev_y, next_y, foot_x)`：筛选与区间相交的 walkable PLATFORM，选择最小 Y 平台；
  - 编写 `_check_ground_support()`：确认当前表面存在且包含脚底 X（`support_margin = 4.0`），支持 `_rebind_surface()`；
  - 处理边缘掉落：保留水平速度自然转为 `FALL`；
  - 处理 Drag 释放与 Snap：`snap_tolerance = 8.0`；
  - 实现窗口跟随：根据窗口位移同步调整小猫坐标，超过 `MAX_SURFACE_ATTACH_DELTA = 150.0` 时脱落。
- **Phase 2: SurfaceWorldModel 接口与窗口追踪 (`scripts/world/surface_world_model.gd`)**
  - 增加 `get_surface_at(x, y, tol_y, tol_x)` 查询接口，便于快速判定脚下支撑与 Rebind；
  - 记录各窗口在更新前后的位置变动字典 `window_deltas`，供小猫读取以实现平滑跟随。
- **Phase 3: F10 物理调试与全局输入 (`scripts/main.gd`)**
  - 绑定 `KEY_F10` 与 Surface Pro 友好键（如 `KEY_N` / `KEY_M`）切换物理调试显示；
  - 绘制脚底点、当前站立表面加粗高亮与下落射线。
- **Phase 4: 自动化单元与集成自验证**
  - 在 `scripts/test_runner.gd` 中补充多表面落脚、高速不穿透、从下向上穿过、边缘掉落、窗口位移跟随等测试用例；
  - 在 `scripts/test_integration.gd` 中增加窗口感知与下落着陆全链路测试；
  - 重新打包 `DesktopCat_Standalone.exe` 并测试。
