# 20260903 Windows 顶层窗口几何感知方案 (T11)

## 1. 核心目标
构建桌面宠物首个正式外部感知服务（External Perception Service），利用 Win32 API 采集当前屏幕上的可见顶层窗口几何尺寸（x, y, width, height），转换为当前 Overlay 局部坐标并进行屏幕矩形裁剪（Rect Clipping），通过 T10 TCP Bridge（NDJSON）发送给 Godot 的 `WindowWorldModel` 存储。
提供 F8 快捷键进行纯线框 Debug 绘制，不创建物理碰撞体，不捕获鼠标穿透，不截图，不引入 AI/CV 依赖，保持极致轻量。

## 2. 总体架构设计

### 2.1 外部感知服务 (`tools/perception/window_perception.py`)
- **零第三方依赖**：仅使用 Python 标准库 + `ctypes`（调用 `user32.dll` 与 `dwmapi.dll`）；
- **Win32 窗口枚举与过滤**：
  - 调用 `EnumWindows` 枚举顶层窗口；
  - 过滤：不可见（`IsWindowVisible`）、最小化（`IsIconic`）、零尺寸/微型辅助窗口（宽高 < 10px）、桌面托盘与系统壁纸窗口；
  - 过滤自身：排除 Perception 自身控制台（`GetConsoleWindow()`）与 DesktopCat Overlay 窗口（基于 HWND / 类名 / 进程）；
  - 窗口边框精度：使用 `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` 剔除 Windows 阴影偏移，回退使用 `GetWindowRect`；
- **虚拟桌面多显示器坐标转换与裁剪**：
  - 从 Godot `hello` / `status` 获取 Cat 所在屏幕全局矩形（`screen_x, screen_y, width, height`）；
  - 将窗口全局坐标转换为当前 Overlay 局部坐标（`local_x, local_y`）；
  - 跨屏窗口执行严格矩形求交与裁剪，保证坐标落在 `[0, 0, width, height]` 内部；
- **变动检测与低频扫描**：
  - 扫描频率 5Hz（200ms），比较前后两次窗口几何列表；
  - 仅在窗口新增、消失、移动、缩放或前台切换时递增 `revision` 并发送 `window_snapshot`，静止时零开销；
- **自动重连**：连接断开或 Godot 未启动时以 2.0s 间隔低频重连。

### 2.2 协议扩展 (`docs/external_bridge_protocol.md`)
- 新增 `window_snapshot` 消息信封，包含 `revision`、`screen`、`windows` 数组（限制 `MAX_WINDOWS = 256`）；
- 严格类型校验与异常拦截，确保 Godot 永不崩溃。

### 2.3 Godot 端数据模型与调试绘制 (`scripts/world/window_world_model.gd`)
- 仅作为纯几何世界数据模型存储，不生成任何 Physics / Collision 节点；
- 接入 F8 快捷键，在透明 Overlay 上以 2px 细线绘制窗口外框与窗口 ID，不拦截鼠标，不影响底层窗口点击。
