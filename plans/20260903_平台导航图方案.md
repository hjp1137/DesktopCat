# 平台导航图系统 (Platform Navigation Graph) 实施方案 (T17)

## 一、核心定位与目标
基于 T16 最终融合的 `SurfaceWorldModel`，构建一个纯几何与运动学可达性分析的轻量有向图：`PlatformNavigationGraph`。
1. **只负责分析、建图、空间查询与 Debug 呈现**，绝对不直接控制 Cat 执行跳跃或寻路（属于 T18）；
2. **以 Cat 真实物理为唯一事实来源**：复用 T06/T13 的 `gravity`、`jump_velocity`、`walk_speed`、`run_speed`、`body_radius` 与 `support_margin`，不复制代码 Magic Number；
3. **严格遵守 One-Way Platform 语义**：仅在下落阶段（Falling Solution）判定 Landing，向上穿越平台绝不算着陆；
4. **弹道阻挡与拦截检测**：轨迹若提前穿过中间更高平台，则截断直连 Edge；
5. **Drop 与自然下落**：从平台边缘自然下落，且仅连接垂直下落路径上碰到的第一个表面。

## 二、架构设计与核心组件
```text
Unified SurfaceWorld ──> PlatformNavigationGraph ──> Reachability Analysis ──> Navigation Edges
   (surface_world_model)     (150ms Debounce)       (Ballistics / Swept)       (JUMP_WALK, JUMP_RUN, DROP)
```

1. **`CatMovementCapabilities` (`scripts/navigation/cat_movement_capabilities.gd`)**：
   - 提取自 `Cat` 节点的真实物理属性接口；
   - 导出理论最大跳高 $H_{max} = v_0^2 / (2g)$；
   - 导出同高理论飞行时间 $T = 2|v_0| / g$；
   - 导出理论最大 Walk / Run 水平距离；
   - 提供求解下落着陆时间 $t_{land}$ 与空间搜索包围盒的能力。
2. **`NavigationNode` (`scripts/navigation/navigation_node.gd`)**：
   - 封装 walkable Platform，绑定 `surface_id`；
   - 扣除 Cat 半宽与安全裕量计算 `safe_x1`, `safe_x2`；安全宽度不足则标为不可导航。
3. **`NavigationEdge` (`scripts/navigation/navigation_edge.gd`)**：
   - 类型：`JUMP_WALK`、`JUMP_RUN`、`DROP`；
   - 保存起跳区间 `[takeoff_x_min, takeoff_x_max]`、落地区间 `[landing_x_min, landing_x_max]`；
   - 保存所需速度模式、飞行时间、水平/垂直跨度与基础 Cost 权重。
4. **`PlatformNavigationGraph` (`scripts/navigation/platform_navigation_graph.gd`)**：
   - 空间初筛（Spatial Prefilter）：排除超出最大高度差或水平射程的候选对；
   - 弹道求解与中间平台拦截剔除（Trajectory Occlusion）；
   - 原子提交（Atomic Commit）与 150ms Debounce 防抖；
   - 提供丰富的查询 API；
   - 支持 `F14`（及免 Fn 键 `G` / `T`）HUD 调试绘制，仅高亮小猫当前所在平台的出度边。
