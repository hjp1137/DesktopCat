# 20260903 轻量视觉几何感知方案 (T15)

## 1. 目标与定位
- **核心定位**：建立 DesktopCat 第三类感知源——轻量视觉几何感知 Provider（Visual Geometry Perception Provider），用于发现 UI Automation 无法感知的横线、竖线、自绘卡片/Canvas 边框、网页视觉分隔线及无语义长方形；
- **纯轻量几何约束**：仅提取 `LINE`（水平/垂直）与 `RECT` 轻量几何数据；严禁文字识别、图片理解、人脸检测、物体分类，严禁引入大模型、云 AI、OCR、YOLO、OpenCV、PyTorch；
- **屏幕像素私密性**：屏幕捕获仅瞬时在 Perception 服务内存中进行灰度差分分析，绝不发送给 Godot（禁止图片/RGB/Base64 进 Bridge），绝不写磁盘、绝不落盘、绝不上网；
- **物理与解耦**：本阶段只构建 `VisualWorldModel` 与 `F12` 调试线框可视化；**严禁将视觉线框加入 Surface 物理世界，不破坏 T13 多表面行走与着陆**（留待 T16 Surface Fusion 统一去重与融合）。

## 2. 总体数据链路
```
Windows Desktop Screen Pixels
       ↓ (Windows 原生 GDI BitBlt + GetDIBits，零第三方依赖，内存Buffer复用)
Downsampled Grayscale Buffer (ANALYSIS_SCALE = 0.25, e.g. 640x360)
       ↓
Screen Change Detection (32x18 网格亮度差分，静态时跳过完整计算)
       ↓
Horizontal & Vertical Edge + Run-Length Filter (MIN_LINE_LENGTH = 60px)
       ↓
Line Merge + Approximate Rect Composition (MIN_RECT = 64x40px)
       ↓
Coordinate Quantization (4px) + Temporal Stability (连续2次确认出现/消失)
       ↓ (T15 NDJSON 协议: visual_snapshot, 限制最多 300 个几何)
ExternalBridge (Godot 47831)
       ↓
VisualWorldModel (scripts/world/visual_world_model.gd)
       ↓ (F12 / J 调试线框渲染，纯 Draw 不捕获鼠标穿透)
Debug Canvas Rendering
```

## 3. 性能控制与关键参数集中配置
- `SCAN_HZ = 2.0`（普通 2Hz，变化时最高 3~5Hz，绝不超 10Hz）；
- `ANALYSIS_SCALE = 0.25`（2560x1440 降采样至 640x360，CPU 极致轻量）；
- `SCREEN_CHANGE_THRESHOLD = 3.0`（32x18 网格均值变动阈值，静态网页几乎零消耗）；
- `EDGE_THRESHOLD = 28`（灰度梯度差分阈值，过滤弱纹理与反走样边缘）；
- `MIN_VISUAL_LINE_LENGTH = 60.0` px（排除字号笔画与小图标，杜绝文字噪声）；
- `LINE_MERGE_Y_TOLERANCE = 4.0` px，`LINE_MERGE_GAP = 16.0` px；
- `MIN_VISUAL_RECT_WIDTH = 64.0` px，`MIN_VISUAL_RECT_HEIGHT = 40.0` px；
- `GEOMETRY_QUANTIZATION = 4.0` px（坐标量化为 4px 网格，抑制像素抖动）；
- `APPEAR_CONFIRM_COUNT = 2`，`DISAPPEAR_CONFIRM_COUNT = 2`（时序稳定性平滑）；
- `MAX_VISUAL_GEOMETRIES = 300`（按尺寸排序优先保留长线与大框）。

## 4. Visual Snapshot 协议与 Godot VisualWorldModel
- **协议格式**：
  ```json
  {
    "v": 1,
    "type": "visual_snapshot",
    "revision": 1,
    "screen": { "index": 0, "width": 2560, "height": 1440 },
    "geometries": [
      { "id": "vg_lh_610_420_960", "type": "LINE", "orientation": "HORIZONTAL", "x1": 420.0, "y1": 610.0, "x2": 960.0, "y2": 610.0 },
      { "id": "vg_rect_420_1100_400_280", "type": "RECT", "x": 1100.0, "y": 420.0, "width": 400.0, "height": 280.0 }
    ]
  }
  ```
- **Godot `VisualWorldModel`**：
  - 存储 `geometries_by_id` 与版本号 `latest_revision`；
  - 提供 `get_lines()`, `get_rects()`, `get_horizontal_lines()`, `get_vertical_lines()`, `get_geometries_near()` 查询；
  - `_draw()` 渲染彩色线框（水平线暖橙、垂直线金黄、矩形紫红），`F12` / `J` 键切换，不影响全屏鼠标穿透。
