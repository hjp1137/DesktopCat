# 平台边缘抓取与悬挂系统 (Platform Edge Grab & Hang) 方案 (T19)

## 一、方案目标与核心理念
在桌面多表面物理系统 (T13) 与多 Provider 表面融合 (T16) 的基础上，实现小猫下落过程中的边缘抓取 (Edge Grab) 与悬挂 (Edge Hang) 系统：
1. **纯物理判定**：当小猫处于下落 (`FALL`) 阶段且脚底未踩中平台表面时，若身体/前爪扫掠经过可抓取平台的左右端点，且满足速度与几何约束，平滑进入 `EDGE_HANG` 悬挂状态；
2. **零作弊与零磁吸**：严格限制 Grab Zone 容差（X: 14px, Y: 20px）与速度极值，禁止大范围磁力吸附，必须体现“差一点够到”的临界物理手感；
3. **架构完全解耦**：本阶段仅实现 Grab + Hang + Release，不提前实现 Climb-Up 或 Wall Climb，保持现有 T13 物理与 T17/T18 导航规划系统不受损破坏。

## 二、核心架构与数据结构
1. **CatState 扩展**：
   - 新增 `EDGE_HANG` 状态；
   - 悬挂期间 `is_grounded = false`，`current_surface_id = ""`，速度清零并暂停重力模拟。
2. **GrabbedEdge 数据结构 (`scripts/world/grabbed_edge.gd`)**：
   - 记录 `surface_id`、`edge_side` (LEFT / RIGHT)、`edge_x`、`edge_y` 与端点位置；
   - 弱引用表面 ID，每帧基于 `SurfaceWorldModel` 动态重新解析，避免野指针。
3. **抓边候选范围与排除规则**：
   - 仅 walkable 且 orientation 为 TOP 的 `PLATFORM` 顶边左右端点允许抓取；
   - 平台长度必须 $\ge 32\text{ px}$；
   - 彻底排除 `screen:ground`、`screen:top`、`screen:left`、`screen:right` 等屏幕边界表面；
   - 对 Window/Text/Button/Edit/Image/VisualLine 一视同仁。

## 三、物理扫掠抓边算法 (Swept Edge Detection)
1. **抓取点参考与朝向**：
   - 以小猫根节点为基准，定义左右爪抓取参考偏移：`offset_y = -20.0px`, `offset_x = ±12.0px`；
   - 运动方向侧前爪优先判定，高速横移时兼顾双侧；
2. **检测优先级**：
   - 步骤 1：常规 Swept Platform Landing。能踩上平台优先踩上；
   - 步骤 2：仅当未着陆且处于下落 (`FALL`, `vy >= 0`) 时，执行 Edge Grab 检测；
   - 步骤 3：若未抓取，继续正常自由落体。
3. **Outside-side 与速度闸门**：
   - 抓左端点要求小猫主体位于端点左侧附近（$x \le \text{edge.x} + 8\text{px}$）；
   - 抓右端点要求小猫主体位于端点右侧附近（$x \ge \text{edge.x} - 8\text{px}$）；
   - 速度限制：$|v_y| \le 600\text{ px/s}$，$|v_x| \le 280\text{ px/s}$，高速抛掷或穿透时拒绝吸附。
4. **扫掠相交区间**：
   - 计算上一帧爪位置与当前帧爪位置构成的线段，若与端点容差矩形（$X \pm 14\text{px}, Y \pm 20\text{px}$）相交且满足外侧接近，判定抓取成功。

## 四、悬挂控制、指令响应与动态自愈
1. **悬挂定位与朝向**：
   - 抓左端点时小猫面向右（朝向平台内部，`direction = 1.0`）；
   - 抓右端点时小猫面向左（朝向平台内部，`direction = -1.0`）；
   - 锚点偏移：$X = \pm 6\text{px}, Y = +18\text{px}$，呈现爪子抓边、身体下垂的物理观感。
2. **指令交互与释放**：
   - 新增 `RELEASE_EDGE` 指令（按键 `G`，仅在 EDGE_HANG 时触发释放，否则保留 F14）；
   - `DRAG` 拥有最高优先级，鼠标拖拽瞬间解除抓边；
   - 点击小猫时仅发出反馈，不触发原地跳跃脱扣；
   - 普通行走/奔跑/跳跃指令在悬挂时安全忽略；
   - AUTO 模式挂载 2.0～3.5 秒后自动释放下落，COMMAND 模式保持挂载（带长超时保护）。
3. **动态跟踪与 Rebind 容错**：
   - 窗口或元素移动时跟随移动，位移 $> 150\text{px}$ 安全脱落；
   - 表面消失时执行 $16\text{px}$ 范围内的等价边缘重绑，失败则自然下落；
   - T18 Autonomous Jump Planner 检测到目标边缘被抓住时，记录 `PARTIAL_EDGE_GRAB` 并平稳退出，不强制打断悬挂。
4. **F16 可视化调试**：
   - 绘制端点标记（L/R）、抓取判定容差框、小猫抓爪参考点与当前悬挂高亮。
