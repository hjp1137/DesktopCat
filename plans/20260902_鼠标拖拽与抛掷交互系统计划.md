# 20260902 鼠标拖拽与抛掷交互系统计划 (T07)

## 1. 任务目标
实现桌宠核心交互：鼠标左键抓起小猫（Drag）、平滑拖动、快速甩动释放抛出（Throw），利用 T06 现有重力系统完成自然下落与落地恢复，保持点击微跳反馈、鼠标穿透安全管理与多显示器适配。

## 2. 详细技术方案

### 2.1 独立 MouseController (`scripts/mouse_controller.gd`)
- 职责：监听鼠标事件并转化为标准指令发送给 `CommandManager`，不直接修改 Cat 内部变量；
- 区分 Click 与 Drag：记录点击起始位置，移动超出阈值（8 像素）才触发 `DRAG_START`；未超阈值松开则触发原生点击反馈；
- 拖拽过程：发送 `DRAG_MOVE` 携带当前鼠标世界坐标；
- 速度采样与 Throw 估算：记录最近 120ms 样本平滑计算释放速度向量，限制最大抛掷速度（X: 1200 px/s, Y: 1000 px/s）；
- Mouse Passthrough 动态管理与 Fail-safe：拖拽中临时解除穿透以全屏接收 Mouse Up，拖拽结束立即恢复；检测到左键物理释放时自动执行安全 Drag End。

### 2.2 CommandManager 扩展 (`scripts/command_manager.gd`)
- `CatCommand` 扩展增加：`DRAG_START`、`DRAG_MOVE`、`DRAG_END`。

### 2.3 Cat 状态机与 Throw 物理 (`scripts/cat.gd`)
- `CatState` 增加 `DRAG`；
- `DRAG_START`：记录抓取相对偏移 `drag_offset`，暂停重力与计时器；
- `DRAG_MOVE`：根据鼠标坐标与 `drag_offset` 平滑跟随；
- `DRAG_END`：接入 `throw_velocity`，向上进入 `JUMP`，空中进入 `FALL`，复用 T06 重力与落地逻辑；
- 边界安全：顶部限制防止飞出屏幕，左右边界反弹衰减；
- 落地后精确恢复 Drag 前的模式（AUTO 自主走停或 COMMAND 意图）。
