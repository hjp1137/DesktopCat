# 平台抓边与悬挂系统 (Platform Edge Grab & Hang) 成果说明 (T19)

## 一、本次交付内容
在桌面多表面物理系统 (T13) 与多 Provider 表面融合 (T16) 的基础上，构建了完全零作弊、零磁吸的平台抓边与悬挂系统：
1. **抓边数据结构 (`scripts/world/grabbed_edge.gd`)**：
   - 记录弱引用表面 ID、边缘侧别（LEFT = -1, RIGHT = 1）、端点坐标与位置向量；
   - 提供序列化方法 `to_dict()`。
2. **多表面空间抓边查询 (`scripts/world/surface_world_model.gd`)**：
   - 实现 `get_grabbable_edges_in_rect(query_rect)`：严格过滤非屏幕、长 $\ge 32\text{ px}$ 的可站立顶边平台，输出左右端点；
   - 实现 `find_equivalent_edge_near(old_pos, side, tolerance)`：用于边缘表面重绑（Edge Rebind）。
3. **小猫抓边与悬挂物理状态机 (`scripts/cat.gd`)**：
   - **CatState 新增 `EDGE_HANG`**：悬挂时 `is_grounded = false`，`current_surface_id = ""`，垂直与水平速度清零，暂停重力物理；
   - **双前爪参考点**：基于小猫根节点建立稳定物理抓点偏移（$X = \pm 12\text{ px}, Y = -20\text{ px}$），不受 Sprite 尺寸波动干扰；
   - **严格优先级**：下落 (`FALL`) 时优先执行 Swept Platform Landing，能踩上平台优先踩上；未着陆时才执行 Swept Edge Grab 检测；
   - **零磁吸与接近判断**：严格限制抓取容差（X: 14px, Y: 20px）与速度极值（$v_y \le 600\text{ px/s}, |v_x| \le 280\text{ px/s}$），限定小猫必须从平台外侧（Outside-side）接近；
   - **悬挂定位与朝向自适应**：挂在左端点时朝向右侧平台，挂在右端点时朝向左侧平台；设置稳定下垂挂边偏移（$X = \pm 6\text{ px}, Y = +18\text{ px}$）；
   - **动态表面跟踪与自愈**：平台缓慢移动时跟随端点平移；位移 $> 150\text{ px}$ 时安全脱落；表面消失时自动尝试等价重绑，失败则自然下落；
   - **AUTO 与 COMMAND 模式区分**：AUTO 模式悬挂 2.0～3.5 秒后自动释放下落；COMMAND 模式下保持挂载（带长安全超时保护）；
   - **指令与交互响应**：支持 `RELEASE_EDGE` 指令（按键 `G` 触发，未悬挂时保留 F14 切换）；鼠标拖拽（`DRAG`）最高优先级瞬间脱扣；点击小猫抑制脱钩跳跃。
4. **自主跳跃规划器协同 (`scripts/navigation/autonomous_jump_planner.gd`)**：
   - 滞空阶段检测到小猫进入 `EDGE_HANG` 时，记录 `partial_edge_grab`，平稳退出规划，不强行将小猫判为失败超时或重置模式。
5. **F16 可视化调试支持 (`scripts/main.gd`, `scripts/external_bridge.gd`, `scripts/cat.gd`)**：
   - 快捷键 `F16`（免 Fn 键 `Z`）切换调试视图；
   - 实时绘制周围平台端点、L/R 标记、Grab Zone 方框、小猫双侧抓点及悬挂锚点连线。
