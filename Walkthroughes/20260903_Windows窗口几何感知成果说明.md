# 20260903 Windows 窗口几何感知成果说明 (T11)

## 1. 任务目标
建立首个正式外部感知服务（External Perception Service），利用 Win32 API 采集当前屏幕上的可见顶层窗口几何尺寸（x, y, width, height），转换为当前 Overlay 局部坐标并进行屏幕矩形裁剪（Rect Clipping），通过 T10 TCP Bridge（NDJSON）发送给 Godot 的 `WindowWorldModel` 存储。提供 F8 快捷键进行纯线框 Debug 绘制，不创建物理碰撞体，不捕获鼠标穿透，不截图，不引入 AI/CV 依赖，保持极致轻量。

## 2. 核心改动
1. **外部感知服务 (`tools/perception/window_perception.py`)**：
   - 仅使用 Python 标准库 + `ctypes`（`user32.dll` + `dwmapi.dll`），零第三方包；
   - 调用 `EnumWindows` 枚举顶层窗口，通过 `DwmGetWindowAttribute` 获取真实精确扩展外框；
   - 严格过滤：不可见窗口（`IsWindowVisible`）、最小化窗口（`IsIconic`）、尺寸 <= 32px 的微型辅助窗口、系统任务栏与壁纸；
   - 自动过滤自身控制台（`GetConsoleWindow()`）与 DesktopCat Overlay 自身；
   - 虚拟桌面与多显示器适配：通过 `MonitorFromWindow` 识别小猫所在物理屏幕工作区，根据 Overlay 分辨率执行高 DPI 缩放映射与当前屏幕矩形裁剪（Rect Clipping）；
   - 5Hz 低频扫描与变动检测（Change Detection）：比较窗口几何签名，仅在窗口新增、消失、移动、缩放或前台切换时发送 `window_snapshot`，静止时零网络数据传输；
   - 掉线平滑重连：每 2.0s 自动低频重试连接，不崩溃不占用额外 CPU。
2. **数据模型与渲染 (`scripts/world/window_world_model.gd`)**：
   - 实现纯几何数据模型存储（`windows_by_id`, `latest_revision`），不生成任何物理碰撞体（StaticBody2D 等），小猫物理逻辑零变动；
   - 支持 `F8` 切换 Debug 线框绘制，使用 `draw_rect` 与 `draw_string` 渲染外框与窗口 ID，不拦截鼠标，不影响底层窗口正常操作。
3. **协议扩展 (`scripts/external_bridge.gd` & `docs/external_bridge_protocol.md`)**：
   - 新增 `window_snapshot` 消息解析，限制 `MAX_WINDOWS = 256` 并校验数值有效性；
   - 状态查询与握手消息中下发 `latest_revision`、屏幕工作区全局坐标与窗口句柄；
   - 客户端断开时自动清理模型窗口缓存，防止幽灵窗口残留。
4. **主场景更新 (`scripts/main.gd`)**：
   - 实例化并挂载 `WindowWorldModel`，接入 `KEY_F8` 快捷键，切换屏幕时清空旧窗口数据。
5. **架构文档 (`docs/screen_world_architecture.md`)**：
   - 记录后续从 Windows API 到 Platform 表面提取、动态碰撞体与导航图的演进路线。

## 3. 验证结果
- 运行单元测试与集成测试全部通过，无语法或逻辑异常；
- 独立 EXE `DesktopCat_Standalone.exe` 与感知服务实时对接测试，成功接收 `window_snapshot`；
- 5Hz 扫描 CPU 占用率测试结果为 0.00%（桌面静止时零网络数据包）；
- 按 `F8` 切换线框绘制正常，鼠标穿透点击 Chrome / 文件夹等底层应用 100% 保持正常。
