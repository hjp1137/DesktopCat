# 20260902 透明桌面 Overlay 成果说明 (T02)

## 1. 任务背景与目标
将 DesktopCat 改造为透明桌面 Overlay，实现无边框、背景完全透明、Always On Top 置顶、全屏分辨率自适应、小猫全屏左右巡逻与 ESC/Alt+F4 安全退出。

## 2. 核心改动
1. **项目配置与透明支持 (`project.godot`)**：
   - 启用 `window/size/borderless=true`、`window/size/always_on_top=true`、`window/size/transparent=true`；
   - 启用 `window/per_pixel_transparency/allowed=true` 与 `rendering/viewport/transparent_background=true`。
2. **主场景初始化与退出机制 (`scripts/main.gd`)**：
   - 在 `_setup_transparent_overlay()` 中动态读取当前屏幕 ID、物理位置与分辨率尺寸（在本机识别为 2880x1920），设置窗口覆盖整个主显示器；
   - 监听 ESC 按键触发 `get_tree().quit()` 安全退出；
3. **小猫移动与边界全屏适配 (`scripts/cat.gd`)**：
   - 视口自适应扩大到 2880x1920，小猫在左右两端屏幕边缘（[24, 2856]）触碰反弹转向；
4. **自动化测试**：
   - 单元测试与 ESC 退出集成测试全部通过。

## 3. 验证结果
- 本机屏幕自动识别为：屏幕 ID 0，位置 `(810, 3240)`，尺寸 `(2880, 1920)`；
- 真实窗口运行下 Vulkan Forward+ 渲染后端成功启动；
- 窗口无边框、背景逐像素透明透显 Windows 桌面；
- 小猫在 2880 宽全屏范围巡逻并在 2856.0 边界反弹；
- ESC 与 Alt+F4 退出逻辑正常。
