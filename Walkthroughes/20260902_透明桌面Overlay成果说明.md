# 20260902 透明桌面 Overlay 成果说明 (T02)

## 1. 任务背景与目标
将 DesktopCat 改造为透明桌面 Overlay，实现无边框、背景完全透明、Always On Top 置顶、全屏分辨率自适应、小猫全屏左右巡逻与 ESC/Alt+F4 安全退出。

## 2. 核心改动
1. **渲染器与透明背景优化 (`project.godot` & `scripts/main.gd`)**：
   - 针对 Windows DWM 合成兼容性，将渲染方法设定为 `gl_compatibility`；
   - 在 `project.godot` 与 `_ready()` 中显式配置清屏颜色 `RenderingServer.set_default_clear_color(Color(0, 0, 0, 0))` 与 `transparent_bg = true`，消除默认黑色底色；
   - 启用 `borderless=true`、`always_on_top=true`、`transparent=true` 与 `per_pixel_transparency/allowed=true`。
2. **主场景初始化与退出机制 (`scripts/main.gd`)**：
   - 动态读取当前屏幕 ID、物理位置与分辨率尺寸（在本机识别为 2880x1920），设置窗口覆盖整个主显示器；
   - 监听 ESC 按键触发 `get_tree().quit()` 安全退出；
3. **小猫移动与边界全屏适配 (`scripts/cat.gd`)**：
   - 视口自适应扩大到 2880x1920，小猫在左右两端屏幕边缘（[24, 2856]）触碰反弹转向；
4. **独立 EXE 构建 (`scripts/build_standalone.gd`)**：
   - 支持自动化将项目打包为单文件免安装可执行程序 `build/DesktopCat_Standalone.exe`。

## 3. 验证结果
- OpenGL Compatibility 驱动启动正常，桌面逐像素透明透显；
- 黑色背景问题已彻底修复；
- 小猫在 2880 宽全屏范围巡逻并在 2856.0 边界反弹；
- ESC 与 Alt+F4 退出正常。
