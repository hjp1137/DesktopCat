# 20260903 本地外部感知桥接通道成果说明 (T10)

## 1. 任务目标
建立 DesktopCat (Godot 4.7.2) 与未来外部感知服务之间极轻量、非阻塞的本地通信基础设施（Local TCP Server on `127.0.0.1:47831`），采用 UTF-8 + NDJSON (v1) 协议规范，仅传递结构化感知与几何数据，保持现有小猫行为零干扰。

## 2. 核心改动
1. **ExternalBridge 模块 (`scripts/external_bridge.gd`)**：
   - 使用 Godot 4 原生 `TCPServer` 监听 `127.0.0.1:47831`，非阻塞 poll 处理客户端；
   - 限制单条消息最大 256KB、输入缓冲最大 512KB，支持 NDJSON 行切包；
   - 实现消息信封规范：`hello`, `ping`/`pong`, `get_status`/`status`, `command`, `error` 与预留 `surface_snapshot`；
   - 白名单验证分发至 `CommandManager`，坐标有效性校验（NaN/无穷大/缺失防护）；
   - 客户端断开与重连平滑处理，保证小猫状态不被外界连接状态异常破坏；
2. **主场景集成 (`scripts/main.gd`)**：
   - 挂载 `ExternalBridge` 节点，提供 `get_overlay_info()` 获取屏幕与视口数据；
3. **Python 标准库测试客户端 (`tools/bridge_test_client.py`)**：
   - 仅依赖 Python 标准库（socket/json/threading），支持交互控制与 20Hz 压力测试；
4. **协议文档与规则 (`docs/external_bridge_protocol.md` & `.gitignore`)**：
   - 详细记录协议规范与几何数据传输设计；补充 Python 缓存文件忽略项；
5. **测试与单文件构建**：
   - 单元测试与集成测试全部通过，单文件独立版 `build/DesktopCat_Standalone.exe` 重新生成。

## 3. 验证结果
- 无客户端接入时 DesktopCat 一切功能（移动、生活调度、鼠标穿透、拖拽等）完全正常；
- Python 客户端连接成功接收 `hello`，`ping`/`pong` 与 `get_status` 响应正常；
- 发送 `jump`、`sit`、`move` 等外部指令均无缝路由至 `CommandManager`，效果与本地键盘一致；
- 畸形 JSON、未知指令与溢出攻击被安全拦截，程序无任何崩溃；
- 20Hz 压力测试平滑运行，CPU 与内存无异常；客户端断开后自动支持平滑重连。
