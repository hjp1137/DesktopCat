# 20260903 统一表面融合与几何简化成果说明 (T16)

## 一、任务背景与核心目标

在 T11~T15 的持续演进中，DesktopCat 建立了三类感知来源：
1. **Window Geometry** (T11/T12)：窗口几何、Z-Order 层级与遮挡切分；
2. **UI Automation Geometry** (T14)：窗口内部结构化 UI 元素（按钮、输入框、文本、图片等）；
3. **Visual Geometry** (T15)：原生轻量级视觉横线、竖线与矩形。

本任务（T16：Unified Surface Fusion & Simplification）的核心目标：
建立统一表面融合器（`SurfaceFusionBuilder`），将三大感知源统一转化为标准 `SurfaceCandidate`，经过类型过滤、文本同行合并、高Z窗口遮挡裁剪、跨源重叠去重、近共线合并、4px 网格坐标量化与时序 Grace 缓冲保护，最终提交至唯一的物理世界模型 `SurfaceWorldModel`，直接赋能 T13 Multi-Surface Physics，使小猫无需任何特殊判断即可在 Windows 文本、按钮、输入框、图片与视觉线条上行走、站立、下落着陆（Swept Landing）与坐下。

## 二、架构设计与核心数据链

### 统一数据流水线
```text
WindowWorldModel ──┐
UIElementWorldModel──┼──> SurfaceFusionBuilder ──> Simplification ──> SurfaceWorldModel ──> T13 Physics ──> 🐱
VisualWorldModel ──┘         (50ms Debounce)      (Dedup/Merge/Grace)   (唯一物理入口)
```

1. **统一候选标准 (`SurfaceCandidate`)**：
   - 携带 `candidate_id`、`source_type` (SCREEN/WINDOW/UIA/VISUAL)、`source_id`、`source_window_id`、`element_type`、`surface_type`、`orientation`、`priority` (100/90/80/60) 与 `source_aliases`。
2. **优先级矩阵 (Source Priority)**：
   - `SCREEN (100)` > `WINDOW (90)` > `UIA (80)` > `VISUAL (60)`。
3. **过滤与简化流水线**：
   - **容器过滤**：剔除 `Pane`, `Group`, `Document`, `List`, `Tree`, `Toolbar`, `Menu`，优先保留具体子控件顶边；
   - **同行文本合并**：同一窗口内 Y 偏差在 `MERGE_Y_TOLERANCE (4.0px)` 且水平间距在 `MERGE_GAP (16.0px)` 内的 Text 片段自动合并为连续平台；
   - **窗口遮挡裁剪**：子控件与视觉几何根据高 Z-Order 窗口区间自动执行 `_subtract_interval` 裁剪；
   - **重叠去重与并集扩展**：水平重叠率达到 `OVERLAP_DEDUP_THRESHOLD (80%)` 时保留高优先级来源并将其几何外扩取并集，记录别名；
   - **网格量化与防抖**：坐标全部量化为 4px (`FUSION_QUANTIZATION = 4.0`)，几何签名不变时不递增 revision；
   - **丢失 Grace 保护**：UI/Visual 表面临时漏检缓冲保留 `FINAL_SURFACE_MISSING_GRACE_MS = 600ms`（Window 为 100ms）。

## 三、验证与调试

### 1. 调试与快捷键
- **F13 融合诊断 HUD**（Surface Pro 免 Fn 键：`H` 或 `Y`）：
  实时展示各感知源候选数（Screen、Window、UIA、Visual）、过滤细分（Small、Nested、Dedup、Merged）以及全流程融合耗时（ms）；
- **F9 物理表面视图**（免 Fn 键：`=` / `B` / `P`）：绘制融合后最终生效的绿线平台与黄线墙体；
- **F8/F10/F11/F12**：分别展示窗口、接触点、UI Automation 与 Visual 几何调试线框。

### 2. 自动化验证闭环
- **全量单元测试 (`scripts/test_runner.gd`)**：共 34 项测试（含 T16 新增的容器过滤、同行文本合并、跨源去重与外扩并集、共线合并、窗口遮挡裁剪、原子提交与防抖、Grace 保护期）100% 通过；
- **端到端集成测试 (`scripts/test_integration.gd`)**：三路快照注入后自动融合成统一表面并顺利触发 F8~F13 调试切换，小猫成功执行 Swept Landing 准确着陆并安全退出；
- **多表面落地物理测试 (`scripts/test_fusion_landing.gd`)**：小猫分别从空中下落精准着陆在 UIA Button、UIA Text 与 Visual Line 表面并切换为走动与站立状态。
