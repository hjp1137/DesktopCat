# 平台边缘攀爬翻越系统 (Platform Edge Climb-Up) 成果说明 (T20)

## 一、本次交付内容
在 T19 平台抓边与悬挂系统 (Platform Edge Grab & Hang) 的基础上，构建了完全零作弊、两段式受控轨迹的平台边缘翻越登顶系统：
1. **正式 CatState 扩展 (`scripts/cat.gd`)**：
   - 新增正式状态 `CLIMB_UP`，严禁通过失控 Tween + IDLE 绕过状态机；
   - 内部包含 `NONE`, `PULL_UP`, `SHIFT_IN`, `SETTLE` 四个受控运动相位；
   - 攀爬期间 `is_grounded = false`，`current_surface_id = ""`，重力与普通 Landing 暂停，由受控轨迹接管位置更新。
2. **ClimbTarget 数据结构 (`scripts/world/climb_target.gd`)**：
   - 保存当前所抓表面 ID、端点侧别（LEFT/RIGHT）、端点坐标、落脚目标坐标、PULL_UP 拐点坐标与起始版本号；
   - 严格限定只能翻上抓取的同一个表面，不能空中突变到附近其它表面。
3. **两段式受控运动 (Procedural Motion)**：
   - `PULL_UP` 相位：从挂载锚点垂直拉升至落脚高度（持续 `CLIMB_PULL_UP_DURATION = 0.3`s）；
   - `SHIFT_IN` 相位：从外侧平移至平台内部落脚点（持续 `CLIMB_SHIFT_IN_DURATION = 0.25`s）；
   - 基于 delta 时间累加与 smoothstep 插值，平滑过渡且不依赖特定帧率，严禁瞬间 Teleport。
4. **可行性检查与净空阻挡 (Feasibility & Clearance Check)**：
   - 检查最小平台跨度（$\ge 48\text{ px}$），平台过窄时安全拒绝；
   - 检查落脚区域上方是否存在其他平台或天花板实体遮挡，空间受限时拒绝翻越。
5. **动态表面跟踪与自愈**：
   - 随页面滚动与窗口移动实时更新目标点；位移超过 150px 时安全脱落；表面消失时自动尝试等价重绑，无等价边缘则立即 cancel 转入 `FALL`。
6. **模式与交互控制**：
   - AUTO 模式悬挂后经过 `AUTO_CLIMB_REACTION_DELAY`（0.5s）自然停顿，自动尝试攀爬；
   - COMMAND 模式按 `H` 触发 `CLIMB_UP`；按 `G` 或发送 `RELEASE_EDGE` 立即脱手下落；
   - 鼠标拖拽（`DRAG`）最高优先级瞬间中断攀爬；小猫点击抑制弹跳，保护平稳翻越；
   - `TAB` 切屏前安全取消攀爬并清理抓边状态。
7. **T18 自主规划器深度协同**：
   - 滞空抓到目标边缘时挂起等待小猫翻越；小猫登顶后结算为 `SUCCESS`，统计 `edge_grab_recovery_success`。
8. **F17 可视化调试支持**：
   - 按键 `F17` 切换，绘制悬挂起点、Pull-Up 拐点、Landing 终点、Clearance 框与当前相位。
