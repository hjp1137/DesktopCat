# 20260902 生活行为系统与自主调度器成果说明 (T08)

## 1. 任务目标
为 DesktopCat 建立完整的基础生活行为系统，扩展 `RUN`、`SIT`、`SLEEP` 状态及配套统一指令，并在 AUTO 模式下实现基于权重、持续时长与冷却时间的自主生活行为调度器。

## 2. 核心改动
1. **动画素材与 SpriteFrames (`assets/cat/placeholder/` & `scenes/cat.tscn`)**：
   - 生成 `run`（16 FPS 冲刺）、`sit`（2 FPS 蹲坐）、`sleep`（3 FPS 蜷缩卧倒闭眼）原创帧并配置至 `SpriteFrames`；
2. **状态与指令体系扩展**：
   - 完整 `CatState`：`IDLE`、`WALK`、`RUN`、`SIT`、`SLEEP`、`JUMP`、`FALL`、`DRAG`；
   - 完整 `CatCommand`：`STOP`、`WALK_LEFT`、`WALK_RIGHT`、`RESUME_AUTO`、`JUMP`、`DRAG_START`、`DRAG_MOVE`、`DRAG_END`、`RUN_LEFT`、`RUN_RIGHT`、`SIT`、`SLEEP`、`WAKE`；
3. **生活行为与物理交互**：
   - `RUN`：冲刺速度（220 px/s）明显快于步行（120 px/s），空中跳跃继承冲刺水平速度；
   - `SIT`：静止端坐（3~8 秒）；
   - `SLEEP`：静止卧倒（8~16 秒），可自动醒来或由 `WAKE` 唤醒；收到 JUMP 自动唤醒起跳，被 Drag 抓住立即进入拖拽且落地转为 IDLE 并触发 15 秒睡眠冷却；
4. **自主生活行为调度器**：
   - AUTO 模式下基于权重池（WALK 40%, SIT 25%, IDLE 15%, RUN 15%, SLEEP 5%）、状态持续范围与冷却机制（`sleep_cooldown` 15s, `run_cooldown` 6s）自然流转；具备屏幕边缘感知转向；
5. **快捷键与构建**：
   - 键盘 1~9 与 0 完整覆盖所有指令；
   - 单元测试与集成测试全部通过，单文件独立版 `build/DesktopCat_Standalone.exe` 构建完成。

## 3. 验证结果
- AUTO 模式下小猫在行走、奔跑、端坐、睡觉与待机之间平滑自主流转；
- 外部指令（6/7/8/9/0）可精准控制各生活行为；
- 睡眠状态下的唤醒、起跳与拖拽打断符合物理与交互逻辑；
- 鼠标穿透、多显示器切换与单文件独立 EXE 验证正常。
