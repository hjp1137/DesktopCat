# T21 垂直墙面附着与攀爬系统成果说明 (2026-09-03)

## 1. 核心功能概述
实现了通用垂直墙面附着与双向攀爬系统（Vertical Wall Attachment & Climbing）。
所有长于 48px 的非屏幕 WALL 表面（包括窗口边框、UI 容器侧边、视觉线条侧边等）均自动赋予 `climbable` 属性。
小猫在 FALL / JUMP / THROW 下落过程中，根据优先级（Landing > Edge Grab > Wall Attach > Fall）自动识别并附着可爬垂直墙面，进入 `WALL_CLING`，并支持向上/向下匀速攀爬（`WALL_CLIMB`）。攀爬到达墙顶时自动平滑过渡为 T19 `EDGE_HANG` 并衔接 T20 `CLIMB_UP` 登顶。

## 2. 核心架构与设计实现
1. **统一表面属性扩展 (`Surface.climbable`)**:
   - `Surface` 与 `SurfaceCandidate` 新增 `climbable: bool = false` 属性，默认仅非屏幕且垂直长度 >= 48.0px 的 WALL 赋予 `climbable = true`。
2. **轻量附着数据结构 (`WallAttachment`)**:
   - 弱引用记录 `wall_surface_id`、几何范围、挂墙侧向（`attach_side`）、附着锚点高度（`anchor_y`）及世界版本号。
3. **物理与状态机扩展 (`CatState.WALL_CLING / WALL_CLIMB`)**:
   - 下落 Swept 抓墙：严格限制速度与水平容差，外侧单向贴靠，零磁吸；
   - 攀爬与状态流转：`WALL_CLIMB_UP` / `WALL_CLIMB_DOWN` / `STOP`；到达 Wall Top 自动转入 `EDGE_HANG` 并翻越登顶；
   - 动态位移跟随、超限脱落（>150px）与等价 Rebind 机制；
   - 优先级与安全中断：DRAG 拖拽及 G 键（`WALL_RELEASE`）瞬间脱手下落，零卡死。

## 3. 调试与控制映射
- **键盘控制**:
  - `U`：当处于 `WALL_CLING` 或 `WALL_CLIMB` 时向上爬行（`WALL_CLIMB_UP`）；
  - `J`：当处于 `WALL_CLING` 或 `WALL_CLIMB` 时向下爬行（`WALL_CLIMB_DOWN`）；
  - `G`：脱手释放（`WALL_RELEASE`），立即转为下落；
  - `F18`：切换垂直墙面攀爬调试视图，显示墙面竖线、T/B顶底端点与当前附着状态。
- **外部 TCP 指令**:
  - 支持 `WALL_CLIMB_UP` / `WALL_UP`、`WALL_CLIMB_DOWN` / `WALL_DOWN`、`WALL_RELEASE` 与 `TOGGLE_DEBUG_WALL`。
