# 20260903 指针感知、注意力与目标移动系统成果说明 (T09)

## 1. 任务目标
构建通用指针感知与目标移动系统，让 Cat 感知 Windows 鼠标位置并表现出注视（Attention）与好奇跟随（Curiosity Chase），提供输入源无关的通用目标移动接口，保持桌面鼠标穿透与已有状态机体系。

## 2. 核心改动
1. **独立 MousePerceptionController (`scripts/mouse_perception_controller.gd`)**：
   - 使用 `DisplayServer.mouse_get_position()` 读取全局鼠标坐标，并根据当前屏幕可用区域矩形动态计算当前 Overlay 局部坐标与离屏状态；
   - 20Hz 采样感知，计算小猫与鼠标距离以及鼠标移动速度；
   - 被动注意力：`attention_radius = 400.0` px，`attention_exit_radius = 460.0` px，IDLE/SIT 时发送 `LOOK_AT_POSITION`；
   - 好奇跟随 (Curiosity Chase)：AUTO 模式下鼠标快速移动时触发 2.5~4.5 秒轻度追逐，结束后进入 15 秒冷却；
   - 显式调试跟踪：按键 `C` 切换 Debug Follow 模式；
2. **CommandManager 通用目标指令 (`scripts/command_manager.gd`)**：
   - 扩展 `LOOK_AT_POSITION`、`MOVE_TO_POSITION`、`CLEAR_TARGET`，保持输入源无关性；
3. **Cat 状态机与目标移动 (`scripts/cat.gd`)**：
   - 维护通用目标位置，注视具备 20px 死区，移动保持 `pointer_follow_distance = 64.0` px 偏置与 `target_reached_radius = 50.0` px 到达死区；
   - 行走与奔跑状态下移动方向优先，SLEEP/DRAG 状态下忽略注视与跟随；显式用户指令与 DRAG 拥有最高优先级；
4. **测试与单文件 EXE**：
   - 更新单元测试与集成测试，重新打包构建单文件独立版 `build/DesktopCat_Standalone.exe`。

## 3. 验证结果
- 小猫在 IDLE/SIT 下平滑注视鼠标，死区内无朝向抖动；
- 行走/奔跑中朝向保持移动方向，睡眠中不被鼠标打扰；
- 开启 Debug Follow（按 C）小猫平滑跟随鼠标目标，到达后安全停在旁边不压住鼠标；
- 鼠标离开当前屏幕时停止追踪，关闭 Debug Follow（再按 C）自动恢复 AUTO 模式；
- 全屏鼠标穿透、多显示器切换与单文件独立 EXE 验证正常。
