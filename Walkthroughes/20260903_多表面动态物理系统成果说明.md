# 20260903 多表面动态物理系统成果说明 (T13)

## 1. 任务完成概述
T13 正式实现了多表面动态物理系统（Multi-Surface Cat Physics），彻底移除了“世界仅有一个单一 ground_y”的核心假设：
- **物理接触点**：统一以 Cat Root 作为脚底中心，提供 `get_foot_position() -> Vector2`，所有物理着陆与支撑判断均基于脚底参考点；
- **核心模型升级**：将单一地面属性升级为 `current_surface_id` 与 `current_surface`，`screen:ground` 作为特殊 walkable PLATFORM 接入同一套表面物理管线；
- **Swept Landing Detection**：下落（FALL）时采用 `prev_foot_y` 到 `next_foot_y` 跨帧线段扫描，杜绝高速下落穿透平台；多候选平台优先选择首个交叉的最小 Y 平台；
- **单向平台穿透 (One-Way Platform)**：向上跳跃（JUMP）阶段不执行着陆判断，可顺畅从平台下方穿过，待到达顶点下落时才被上方平台承接；
- **连续地面支撑与边缘掉落**：已着陆状态每帧验证当前表面支撑范围（带 `support_margin = 4.0px`），离开边缘自动转为抛物线下落（FALL）；
- **表面重新绑定 (Rebind)**：在脚底附近快速查找同高度有效表面，解决窗口遮挡切分重新编号导致的误坠落；
- **动态窗口移动跟随**：窗口发生位移时小猫同步平移；位移超过 `MAX_SURFACE_ATTACH_DELTA = 150px` 时安全脱落；窗口关闭/最小化/遮挡消失时自动下落；
- **Drag / Throw 完整支持**：抛掷或拖拽释放时支持 `snap_tolerance = 8.0px` 小范围吸附着陆；点击微跳仅作用于 Sprite，不影响接触点；
- **F10 物理调试线框**：按 `F10`（或 `N` / `M`）高亮当前站立表面与脚底接触点，不影响全屏透明鼠标穿透；
- **单文件独立版本**：重新编译构建 `DesktopCat_Standalone.exe` 并通过端到端集成验证。

## 2. 核心修改文件
1. `scripts/cat.gd`：升级多表面物理状态机、Swept Landing、支撑检查、边缘掉落、动态跟随与 F10 调试渲染；
2. `scripts/world/surface_world_model.gd`：增加窗口位移追踪 `window_deltas`、`find_crossed_walkable_surface` 与 `find_support_surface_at` 空间查询接口；
3. `scripts/main.gd`：挂载 SurfaceWorldModel 信号连接，增加 F10 快捷键；
4. `scripts/external_bridge.gd` & `tools/`：支持 `TOGGLE_DEBUG_PHYSICS` 指令，断线时保留最后已知有效快照；
5. `scripts/test_runner.gd` & `scripts/test_integration.gd`：补充 17 项全覆盖单元测试与端到端下落着陆集成测试。
