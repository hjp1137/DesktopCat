# 20260902 正式 Cat 表现层与动画框架成果说明 (T04)

## 1. 任务目标
将小猫表现层由 `_draw()` 升级为 `AnimatedSprite2D`，建立 `idle` 与 `walk` 动画框架及基础走走停停状态机，保持透明 Overlay、鼠标穿透、点击反馈、多屏切换等全部已有功能。

## 2. 核心改动
1. **动画素材与 SpriteFrames (`assets/cat/placeholder/`)**：
   - 生成 64x64 原创 PNG 帧：
     - `idle` 动画：4 帧，4 FPS，循环播放，呼吸起伏与尾巴轻摆；
     - `walk` 动画：6 帧，10 FPS，循环播放，四肢迈步起伏；
2. **场景独立化 (`scenes/cat.tscn`)**：
   - 包含 `Cat` (Node2D, `scripts/cat.gd`)、`AnimatedSprite2D` 和 `Area2D` + `CollisionShape2D`；
   - `scenes/main.tscn` 实例化 `cat.tscn`；
3. **状态机与移动控制 (`scripts/cat.gd`)**：
   - 基础 `IDLE` (停歇 1.5~3.5s) / `WALK` (行走 3~7s) 状态机；
   - 状态切换时触发 `play("idle")` / `play("walk")`，避免每帧重复调用；
   - 行走方向由 `animated_sprite.flip_h` 精准翻转，不修改 `scale.x`；
   - 点击时通过 Tween 控制 `animated_sprite.position.y` 产生 16 像素弹性跳动；
4. **自动化测试与单文件 EXE**：
   - 单元测试与集成测试全部通过；
   - 重新构建单文件独立版 `build/DesktopCat_Standalone.exe`。

## 3. 验证结果
- AnimatedSprite2D 正常驱动 idle / walk 动画；
- 小猫走走停停切换自然，左右朝向翻转准确，脚底无抖动；
- 点击反馈、鼠标穿透与多屏 TAB 切换完全正常；
- 独立 EXE 运行与编辑器运行行为一致，控制台无错误。
