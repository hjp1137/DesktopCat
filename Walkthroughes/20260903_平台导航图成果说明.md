# 平台导航图系统 (Platform Navigation Graph) 成果说明 (T17)

## 一、本次交付内容
基于 T16 最终多源融合的 `SurfaceWorldModel`，成功构建轻量、纯几何且遵循真实运动学的平台导航图系统：
1. **CatMovementCapabilities (`scripts/navigation/cat_movement_capabilities.gd`)**：
   - 提取 Cat 节点的真实物理参数（`gravity=980`, `jump_velocity=-420`, `walk_speed=120`, `run_speed=220`, `body_radius=28`, `landing_margin=14`）；
   - 提供理论最大跳高（90.0px）、同高飞行时间（0.857s）、Walk / Run 理论水平射程、二次下落时间求解方程。
2. **NavigationNode & NavigationEdge (`scripts/navigation/navigation_node.gd`, `navigation_edge.gd`)**：
   - 封装 walkable 平台，扣除小猫半宽与安全裕量，过滤窄短表面；
   - 区分 `JUMP_WALK`、`JUMP_RUN`、`DROP` 三种有向动作类型，保存起跳区间、落地区间、飞行时间与综合代价。
3. **PlatformNavigationGraph (`scripts/navigation/platform_navigation_graph.gd`)**：
   - 支持 150ms 防抖更新与全图原子提交（Atomic Commit）；
   - 采用空间初筛（Spatial Prefilter）快速排除超出垂直跳高极限或水平射程的候选对；
   - 严格遵循 One-Way Platform 语义，仅选用顶点后的下落相交解（Falling Solution）；
   - 实现了连续段轨迹扫掠相交检测（Swept Crossing Occlusion），排除被中间更高平台拦截的假直连边；
   - 支持 Drop 边缘自然下落至首个承接平台；
   - 提供了完整的图查询 API（`get_node`, `get_edges_from`, `get_reachable_surfaces`, `get_edge`, `find_nearest_node` 等）；
   - 支持 F14 调试渲染（免 Fn 键 `G` 切换，`T` 键输出当前导航可达摘要）。
