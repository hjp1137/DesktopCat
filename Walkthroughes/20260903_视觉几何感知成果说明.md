# 20260903 轻量视觉几何感知成果说明 (T15)

## 1. 成果概述
本阶段完成了 DesktopCat 第三类屏幕感知 Provider——**轻量视觉几何感知 Provider（Lightweight Visual Geometry Perception）**。
- **纯几何提取**：基于 Windows 原生 GDI 截屏与降采样（`ANALYSIS_SCALE = 0.25`）灰度梯度分析，提取屏幕中的长水平线、长垂直线与明显长方形（LINE、RECT）；
- **零隐私泄露与零模型依赖**：绝对禁止文字识别、禁止人脸/物体识别、禁止大模型、禁止云 AI、禁止 OpenCV，不落盘、不传像素流，Godot 端仅接收结构化矢量几何；
- **高性能静止跳过**：内置 32x18 缩略网格亮度变动检测，静态网页与窗口跳过完整分析（耗时仅 0.17ms）；
- **物理世界完全解耦**：视觉几何仅入驻 `VisualWorldModel` 与 `F12` 调试线框可视化，绝不直接生成 Surface 物理碰撞，原 T13 窗口平台行走与跳跃 100% 保持完好。

## 2. 核心架构与实现细节
1. **参数集中配置 (`tools/perception/visual_perception_config.py`)**：
   - 集中统一管理 `SCAN_HZ=2.0`、`ANALYSIS_SCALE=0.25`、`EDGE_THRESHOLD=28`、`MIN_VISUAL_LINE_LENGTH=60.0`、`MAX_VISUAL_GEOMETRIES=300` 等算法超参；
2. **视觉感知服务 (`tools/perception/visual_perception.py`)**：
   - 采用 Windows 原生 `user32` + `gdi32`（`StretchBlt` + `GetDIBits`）复用内存 DC 与 Bitmap Buffer，截屏降采样耗时实测仅 15ms~25ms；
   - 边缘游程与合并算法，并做 4px 坐标量化与连续 2 帧出现/消失时序平滑；
   - 支持全局快捷键 `F12` 及免 Fn 键 `J` 控制调试呈现；
3. **Godot 几何模型 (`scripts/world/visual_world_model.gd`)**：
   - 维护 `geometries_by_id` 与版本防倒退；
   - 提供 `get_lines()`, `get_rects()`, `get_horizontal_lines()`, `get_vertical_lines()`, `get_geometries_near()` 空间与分类查询；
   - `_draw()` 绘制水平暖橙、垂直金黄、矩形紫红线框，不影响鼠标穿透。

## 3. 自验证与测试结果
1. **单元测试 (`scripts/test_runner.gd`)**：
   - 测试 23~27 全量覆盖视觉快照解析、版本防倒退、极值非法数值过滤、分类与空间查询 API、F12 调试开关；27 项单元测试全部一次性通过。
2. **集成测试 (`scripts/test_integration.gd`)**：
   - 验证通过 TCP 47831 同时并发接收 `window_snapshot`, `ui_snapshot`, `visual_snapshot`；
   - 验证 F8, F9, F10, F11, F12 调试开关多层共存；
   - 验证小猫下落着陆到 Chrome 顶边平台（T13 物理完整保留，着陆 `0x30094:top`, `y=150.0`）。
3. **实机性能实测**：
   - 降采样尺寸：640x360（2560x1440 的 0.25 缩放）；
   - GDI 内存复用抓屏耗时：~15ms~20ms；
   - 画面变化检测耗时：~0.17ms；
   - 几何提取耗时：~19ms~30ms；
   - 静态跳过率：>90%（桌面静止时几乎零 CPU 消耗）；
   - 稳定输出几何数量：~30-80 个，无文字噪点爆炸。
