# 20260902 跳跃、重力与下落物理系统成果说明 (T06)

## 1. 任务目标
为 DesktopCat 建立完整的垂直物理运动系统（JUMP → FALL → LAND），支持通过统一 `CommandManager` 发送 `JUMP` 指令，并保持水平运动、点击视觉反馈分离、空中鼠标穿透跟随、多显示器适配及安全退出。

## 2. 核心改动
1. **物理参数与地面基准计算 (`scripts/cat.gd`)**：
   - 配置重力 `gravity = 980.0` px/s²，起跳速度 `jump_velocity = -420.0` px/s（跳跃高度约 90 像素，自身高度 2 倍，时长约 0.85 秒）；
   - 动态基于当前屏幕可用高度计算 `ground_y = vp_size.y - 48.0`，杜绝漂移与穿地；
2. **状态机与完整跳跃周期**：
   - 扩展 `CatState { IDLE, WALK, JUMP, FALL }`；
   - 起跳：仅在 `is_grounded` 时起跳，空中再次收到 JUMP 自动忽略防二段跳；
   - 最高点：当 `vertical_velocity >= 0` 时平滑转为 `FALL` 状态；
   - 落地着陆：当 `position.y >= ground_y` 时钳制坐标，`is_grounded = true`，并根据当前模式（AUTO / COMMAND）无缝恢复原意图行为；
   - 空中保留原有水平移动速度，碰壁正常反弹；
3. **点击反馈与物理彻底分离**：
   - 点击小猫触发的 16px 上弹仅操作 `_animated_sprite.position.y` 局部视觉 offset（Tween 动画），绝对不修改根节点的真实 `position.y` 或垂直物理速度；
4. **CommandManager 与快捷键 (`scripts/command_manager.gd` & `scripts/main.gd`)**：
   - 扩展 `CatCommand` 增加 `JUMP`，主场景按键 `5` 统一分发 `JUMP` 命令；
   - 适配 TAB 切换显示器时重置小猫到新屏幕 `ground_y`。

## 3. 验证结果
- 地面按 5 起跳，小猫以抛物线跳跃并自然下落；
- 空中再次按 5 无法二段跳；
- 空中点击小猫视觉反馈正常，物理轨迹不受影响；
- 鼠标穿透区域实时跟随空中 Cat，原地面区域穿透正常；
- 单元测试与集成测试全部通过，单文件独立 EXE 运行正常。
